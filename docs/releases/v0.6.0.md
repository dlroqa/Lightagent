# Lightagent 0.6.0

**Prepared, not released.** This page is the release body for `v0.6.0`. A tag push drafts the GitHub release with generated notes; a manual run of the release workflow is a dry run unless `dry_run` is turned off on the tag. Paste this page above the generated notes before publishing.

0.6.0 is the first release with **Lightagent Desktop**, a native app for macOS (Apple silicon and Intel), Windows x64 and Linux x64. It starts and owns its own bundled runtime and reaches every applicable CLI capability (222 of 222) through the same operations the CLI and the API use: conversations, profiles, providers and models, tools, extensions and MCP servers, skills, memory, knowledge, workers, identity, remote credentials, diagnostics and setup. The CLI is unchanged in name and update path.

## Before you install

- **The installers are not code-signed** (unless this section is replaced at publication). macOS blocks the app until it is allowed in System Settings › Privacy & Security; Windows SmartScreen asks before running it. Check the file against `SHA256SUMS`.
- The Desktop keeps its data in the same Lightagent home as the CLI (`~/.lightagent`); installing, reinstalling and uninstalling the app leave it in place.
- The Desktop does not update itself; install a newer version from its installer.

## Verification

The bundled notices were checked against the crate versions in the shipped binaries: every one is listed at its version with its license text.
