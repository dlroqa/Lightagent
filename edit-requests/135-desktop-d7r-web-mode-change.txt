=== message
Row 52: apply the web mode only as a change; drop setup's unused nonempty

Every Settings save carries the whole settings object, including the web
mode it read. Re-applying that mode on an unrelated save (memory, turns)
would reset what the mode implies: Off and Fetch turn realtime knowledge
off, which silently undid a `lightagent config set rag.realtime_enabled
true`. The mode now applies only when it differs from the configured one,
read before web_enabled is assigned, or when a custom search's URL
changes. The backend test checks that an unrelated save keeps realtime
knowledge on.

setup.rs's nonempty() lost its last callers to WebMode::apply.

    // read, and an unrelated one must not reset what a mode implies
    // (realtime knowledge, the search key).
    let web_before = lightagent_core::WebMode::of(config);
    config.web.enabled = settings.web_enabled;
    if let Some(mode) = settings.web_mode {
        let endpoint = settings
            .web_search_endpoint
            .as_deref()
            .map(str::trim)
            .filter(|url| !url.is_empty());
        let moved = mode == lightagent_core::WebMode::Custom
            && endpoint != config.web.search.endpoint.as_deref();
        if mode != web_before || moved {
            mode.apply(config, endpoint);
        }
    }
