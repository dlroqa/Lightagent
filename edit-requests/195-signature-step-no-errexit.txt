=== message
Keep the signature state step running past a rejected assessment

The job's shell runs with -e, so a plain assignment from spctl, which
exits 3 when it rejects (as it does for every unsigned package), ended
the step before it reported. The step is report-only apart from its
explicit status, so it now turns errexit off.

          # (spctl exits 3 when it rejects, which unsigned packages always are).
          set +e -uo pipefail
