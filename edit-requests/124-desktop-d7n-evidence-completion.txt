Row 48: identity, remote-credential and setup options at every level

An audit of rows 42-46 against the evidence rule (backend, host and
browser for each counted row) found options exercised at one or two
levels only. This adds the missing checks; no product code changes.

- Host (runs.py): identity: issue for one profile (--profile), rotate
  (key id, expiry, secret file), reassign, revoke a grant, suspend.
  remote credentials: keygen; add with operations, an expiry and a
  request budget; rekey from a previous key (a grant the CLI sealed with
  a key made through the host). setup: init with a model (restored);
  a forced Hermes import.
- Browser: identity: issue for one profile; the grants list by profile.
  credentials: add with operations and an expiry. setup: reconfigure with
  a model (restored); a forced import (asks first).
- Backend: desktop_remote_credentials.rs adds operations and an expiry.
