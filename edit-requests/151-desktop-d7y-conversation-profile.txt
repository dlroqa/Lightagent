Row 57: a conversation runs as its own profile (chat --profile)

`lightagent chat --profile X` runs a chat as X without changing the
active profile. The desktop could do this only through a profile switch,
which persists the choice. Now a conversation is bound to one profile when
it is created and runs as that profile, and the active profile stays as
it was (owner decision, 2026-11-04).

- API: for the local operator, every conversation operation can name its
  profile: ?profile= on the /sessions routes (list, search, create, get,
  update, delete, attachments), and `profile` in the POST /runs and
  /sessions/{id}/regenerate bodies. A named profile resolves to that
  profile's own store (profiles/<id>/sessions, the store `chat --profile`
  uses), and its runs are built from it: persona, model, tools, durable
  memory and remote-credential grants, through the run factory chat
  shares. Unnamed, the profile the runtime serves, exactly as before.
- Authorization: naming a profile grants nothing. The operator path is
  reached only after the request is authorized as the local operator,
  and the profile must exist in this home (otherwise 404, nothing
  created; an invalid id is 400). A user in multi-user mode keeps the
  grant-checked `access` path; ownership is unchanged. A conversation is
  found only under its own profile.
- Desktop contract: `profile` is an allowed query on the session
  operations.
- UI: a Profile choice by the conversation list (when there is more than
  one profile) lists that profile's conversations and starts new ones as
  it. It is remembered per viewer and never calls `profile use`.
- Evidence: backend desktop_conversation_profile.rs, host runs.py
  `conversation_profile` (the fake provider now also records each
  request's model and system text), browser e2e/conversation-profile.mjs.
- docs/desktop/DESKTOP_CONVERSATION_PROFILES.md: the local contract, the
  separation of account, profile and conversation identity, and the
  future cloud mapping. Online login and sync are a later stage.

/// The local operator's conversations of one profile: the profile a request
/// names for them, as `lightagent chat --profile` names one for a chat, else
/// the one this server serves. The active profile is not changed. Naming a
/// profile grants nothing by itself: this is reached only once the request
/// is authorized as the local operator, and the profile must exist in this
/// home. A user in multi-user mode is scoped by `access` instead.
fn operator_conversations(
    state: &AppState,
    requested: Option<&str>,
) -> Result<(String, SessionStore), Box<Response>> {
    let Some(raw) = requested.filter(|raw| *raw != state.session_profile) else {
        return Ok((state.session_profile.clone(), state.sessions.clone()));
    };
    let Ok(id) = ProfileId::new(raw) else {
        return Err(Box::new(bad_request("invalid profile id")));
    };
    let Some(root) = home(state) else {
        return Err(Box::new(internal(
            "conversations of another profile need the Lightagent home",
        )));
    };
    let profiles = ProfileStore::new(&root);
    if profiles.load(&id).is_err() {
        return Err(Box::new(
            (
                StatusCode::NOT_FOUND,
                Json(json!({ "error": "no such profile" })),
            )
                .into_response(),
        ));
    }
    let sessions = SessionStore::at_profile(&profiles.handle(&id))
        .keep_history(state.sessions.is_history_kept());
    Ok((id.as_str().to_owned(), sessions))
}

 * `path` for the conversations of `profile`, a conversation-scoped choice as

function forProfile(path: string, profile?: string): string {
  if (!profile) return path;
  return `${path}${path.includes("?") ? "&" : "?"}profile=${encodeURIComponent(profile)}`;
}

// The profile the conversation list shows and new chats run as, when it is
// not the one the runtime serves. A per-viewer convenience.
const PROFILE_KEY = "lightagent.agent.profile";

function readConversationProfile(): string | null {
  try {
    return window.localStorage.getItem(PROFILE_KEY) || null;
  } catch {
    return null;
  }
}

function keepConversationProfile(profile: string | null) {
  try {
    if (profile) window.localStorage.setItem(PROFILE_KEY, profile);
    else window.localStorage.removeItem(PROFILE_KEY);
  } catch {
    // Without storage the choice lasts as long as this page.
  }
}

def scenario_conversation_profile(host, provider, cli):
    """`lightagent chat --profile` through the host: a conversation created
    for another profile is kept and listed under that profile only and runs
    as it (the provider sees its persona), as `chat --profile` runs a chat;
    `chat --profile --session` continues it; the active profile stays as it
    was, for the host's runtime and the CLI."""
    check = Checks("conversation_profile")
    persona = "You answer as the e2e research desk."
    harness.run_cli(cli, "profile", "create", "e2e-research", "--persona", persona)
    active = json.loads(harness.run_cli(cli, "--json", "profile", "list")).get("active")
    scoped = f"{API}/sessions?profile=e2e-research"
    status, created = host.fetch("POST", scoped, {})
    session = (created or {}).get("id")
    check.expect("a conversation created for e2e-research through the host",
                 status == 201 and isinstance(session, str), (status, created))
    if not isinstance(session, str):
        return check
    _, listed = host.fetch("GET", scoped)
    _, default = host.fetch("GET", f"{API}/sessions")
    check.expect("listed under e2e-research, not under the active profile",
                 session in [row.get("id") for row in (listed or {}).get("sessions", [])]
                 and session not in [row.get("id") for row in (default or {}).get("sessions", [])])
    before = len(provider.requests("profile"))
    status, run = host.fetch("POST", f"{API}/runs", {
        "message": "[e2e:profile] Where do herons nest?", "session_id": session, "profile": "e2e-research"})
    if status == 202:
        Stream(host, run["id"]).finish()
    desktop = provider.requests("profile")[before:]
    check.expect("the run through the host is built from e2e-research (its persona)",
                 status == 202 and len(desktop) == 1 and persona in (desktop[0].get("system") or ""),
                 (status, len(desktop)))
    harness.run_cli_input(cli, "[e2e:profile] And egrets?\n/exit\n", "chat", "--profile", "e2e-research")
    by_cli = provider.requests("profile")[before + len(desktop):]
    check.expect("lightagent chat --profile e2e-research sends the same persona and model",
                 len(desktop) == 1 and len(by_cli) >= 1 and persona in (by_cli[-1].get("system") or "")
                 and by_cli[-1].get("model") == desktop[0].get("model"),
                 [request.get("model") for request in desktop + by_cli])
    harness.run_cli_input(cli, "[e2e:profile] Which ones winter here?\n/exit\n",
                          "chat", "--profile", "e2e-research", "--session", session)
    _, saved = host.fetch("GET", f"{API}/sessions/{session}?profile=e2e-research")
    users = [message.get("content") for message in (saved or {}).get("messages", []) if message.get("role") == "user"]
    check.expect("chat --profile e2e-research --session continues the host's conversation",
                 (saved or {}).get("profile") == "e2e-research" and len(users) == 2
                 and "Which ones winter here?" in str(users[-1]), users)
    _, catalog = host.fetch("GET", f"{API}/profiles")
    check.expect("the active profile stays as it was, for the runtime and the CLI",
                 isinstance(active, str) and (catalog or {}).get("active_profile") == active
                 and json.loads(harness.run_cli(cli, "--json", "profile", "list")).get("active") == active,
                 (active, (catalog or {}).get("active_profile")))
    return check

/** An OpenAI-compatible model on loopback that answers "Noted." and keeps what it was sent. */
async function recordingStub(model) {
  const seen = [];
  const chunk = (delta, finish) =>
    `data: ${JSON.stringify({ choices: [{ index: 0, delta, ...(finish ? { finish_reason: finish } : {}) }] })}\n\n`;
  const text = (message) => (typeof message?.content === "string"
    ? message.content
    : (message?.content ?? []).map((part) => part?.text ?? "").join(""));
  const server = createServer((request, response) => {
    let raw = "";
    request.on("data", (part) => { raw += part; });
    request.on("end", () => {
      if (request.method === "GET" && (request.url ?? "").startsWith("/v1/models")) {
        response.writeHead(200, { "content-type": "application/json" });
        return response.end(JSON.stringify({ object: "list", data: [{ id: model }] }));
      }
      let body = {};
      try { body = JSON.parse(raw); } catch { body = {}; }
      const messages = body.messages ?? [];
      seen.push({
        model: body.model,
        system: messages.filter((m) => m.role === "system" || m.role === "developer").map(text).join("\n"),
        user: text([...messages].reverse().find((m) => m.role === "user")),
      });
      response.writeHead(200, { "content-type": "text/event-stream", connection: "close" });
      response.write(chunk({ role: "assistant" }));
      response.write(chunk({ content: "Noted." }));
      response.write(chunk({}, "stop"));
      response.end("data: [DONE]\n\n");
    });
  });
  await new Promise((resolve) => server.listen(0, "127.0.0.1", resolve));
  return {
    seen,
    url: `http://127.0.0.1:${server.address().port}`,
    close: () => {
      server.closeAllConnections?.();
      return new Promise((resolve) => server.close(resolve));
    },
  };
}

/// One authenticated JSON request: the status and the raw body.
fn call(runtime: &Runtime, method: &str, path: &str, body: Option<&str>) -> (u16, String) {
    let mut stream = TcpStream::connect(&runtime.addr).expect("connect");
    stream
        .set_read_timeout(Some(Duration::from_secs(60)))
        .expect("timeout");
    let body = body.unwrap_or("");
    let head = format!(
        "{method} {path} HTTP/1.1\r\nHost: {}\r\nAuthorization: Bearer {KEY}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        runtime.addr,
        body.len()
    );
    stream.write_all(head.as_bytes()).expect("send");
    let mut response = String::new();
    let _ = stream.read_to_string(&mut response);
    let status = response
        .split_whitespace()
        .nth(1)
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    let raw = response
        .split_once("\r\n\r\n")
        .map(|(_, body)| body.to_owned())
        .unwrap_or_default();
    (status, raw)
}

/// Read one request; return its head and body.
fn read_request(stream: &mut TcpStream) -> Option<(String, String)> {
    let _ = stream.set_read_timeout(Some(Duration::from_secs(10)));
    let mut bytes = Vec::new();
    let mut buffer = [0u8; 4096];
    loop {
        if let Some(end) = bytes.windows(4).position(|window| window == b"\r\n\r\n") {
            let head = String::from_utf8_lossy(&bytes[..end]).into_owned();
            let length = head
                .lines()
                .find_map(|line| {
                    line.to_ascii_lowercase()
                        .strip_prefix("content-length:")
                        .map(|value| value.trim().parse::<usize>().unwrap_or(0))
                })
                .unwrap_or(0);
            if bytes.len() >= end + 4 + length {
                let body = String::from_utf8_lossy(&bytes[end + 4..end + 4 + length]).into_owned();
                return Some((head, body));
            }
        }
        match stream.read(&mut buffer) {
            Ok(0) | Err(_) => return None,
            Ok(read) => bytes.extend_from_slice(&buffer[..read]),
        }
    }
}

fn sse(chunks: &[Value]) -> String {
    let mut response =
        "HTTP/1.1 200 OK\r\ncontent-type: text/event-stream\r\nconnection: close\r\n\r\n"
            .to_owned();
    for chunk in chunks {
        response.push_str(&format!("data: {chunk}\n\n"));
    }
    response.push_str("data: [DONE]\n\n");
    response
}

/// A provider that answers every turn "Noted." and keeps each request body.
fn provider() -> (String, Arc<Mutex<Vec<Value>>>) {
    let listener = TcpListener::bind("127.0.0.1:0").expect("listener");
    let url = format!("http://{}", listener.local_addr().expect("address"));
    let bodies = Arc::new(Mutex::new(Vec::new()));
    let kept = Arc::clone(&bodies);
    std::thread::spawn(move || {
        for stream in listener.incoming() {
            let Ok(mut stream) = stream else { continue };
            let kept = Arc::clone(&kept);
            std::thread::spawn(move || {
                let Some((head, body)) = read_request(&mut stream) else {
                    return;
                };
                if head.starts_with("GET") {
                    let response = format!(
                        "HTTP/1.1 200 OK\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{MODELS}",
                        MODELS.len()
                    );
                    let _ = stream.write_all(response.as_bytes());
                    return;
                }
                kept.lock()
                    .expect("bodies")
                    .push(serde_json::from_str(&body).unwrap_or(Value::Null));
                let answer = sse(&[
                    json!({"choices":[{"index":0,"delta":{"role":"assistant","content":"Noted."}}]}),
                    json!({"choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}),
                ]);
                let _ = stream.write_all(answer.as_bytes());
            });
        }
    });
    (url, bodies)
}

/// A message's text, whether a string or a list of parts.
fn text(message: &Value) -> String {
    match &message["content"] {
        Value::String(text) => text.clone(),
        Value::Array(parts) => parts
            .iter()
            .filter_map(|part| part["text"].as_str())
            .collect(),
        _ => String::new(),
    }
}

/// The system text and the model of the latest request whose newest user
/// turn says `said`.
fn sent_for(bodies: &Mutex<Vec<Value>>, said: &str) -> (String, String) {
    let bodies = bodies.lock().expect("bodies");
    let body = bodies
        .iter()
        .rev()
        .find(|body| {
            body["messages"]
                .as_array()
                .and_then(|messages| messages.iter().rev().find(|m| m["role"] == "user"))
                .is_some_and(|message| text(message).contains(said))
        })
        .unwrap_or_else(|| panic!("no request carried {said:?}"));
    let system = body["messages"]
        .as_array()
        .into_iter()
        .flatten()
        .filter(|message| message["role"] == "system" || message["role"] == "developer")
        .map(text)
        .collect::<Vec<_>>()
        .join("\n");
    (system, body["model"].as_str().unwrap_or_default().to_owned())
}

/// Whether the provider was sent `latest` as the newest user turn, after
/// `earlier` and an answer.
fn carried(bodies: &Mutex<Vec<Value>>, latest: &str, earlier: &str) -> bool {
    bodies.lock().expect("bodies").iter().any(|body| {
        let messages = body["messages"].as_array().cloned().unwrap_or_default();
        let Some(last) = messages
            .iter()
            .rposition(|message| message["role"] == "user")
        else {
            return false;
        };
        let before = &messages[..last];
        text(&messages[last]).contains(latest)
            && before
                .iter()
                .any(|message| message["role"] == "user" && text(message).contains(earlier))
            && before.iter().any(|message| message["role"] == "assistant")
    })
}

/// What `role` said in a saved session, in order.
fn said_by(session: &Value, role: &str) -> Vec<String> {
    session["messages"]
        .as_array()
        .into_iter()
        .flatten()
        .filter(|message| message["role"] == role)
        .map(text)
        .collect()
}

        .into_iter()
        .flatten()
        .filter_map(|row| row["id"].as_str())

}

/// One turn over the API in `session`, run as `profile` when one is named,
/// waited for until it completes.
fn turn(runtime: &Runtime, session: &str, profile: Option<&str>, message: &str) {

    if let Some(profile) = profile {
        body["profile"] = json!(profile);
    }
    let (status, raw) = call(runtime, "POST", &format!("{API}/runs"), Some(&body.to_string()));
    assert_eq!(status, 202, "{raw}");

    let deadline = Instant::now() + Duration::from_secs(60);

    }
}

    );
    assert_eq!(status, 200, "{raw}");
    let saved = parsed(&raw);
    assert_eq!(saved["profile"], "research", "{saved}");
    assert_eq!(said_by(&saved, "user"), ["Where do herons nest?"], "{saved}");

    // `chat --profile research` sends what the desktop sent for research.
    chat(&home, &["--profile", "research"], "And egrets?\n/exit\n");
    let (by_cli, cli_model) = sent_for(&bodies, "And egrets?");
    assert!(by_cli.contains(PERSONA), "{by_cli}");
    assert_eq!(cli_model, model);

    // A conversation of the active profile is not research's.
    let plain = new_session(&runtime, None);
    turn(&runtime, &plain, None, "A plain question.");
    let (system, model) = sent_for(&bodies, "A plain question.");
    assert!(!system.contains(PERSONA), "{system}");
    assert_ne!(model, "research-model");

    // `chat --profile research --session <id>` continues the conversation,
    // and the desktop continues after it.
    chat(
        &home,
        &["--profile", "research", "--session", &id],
        "Which ones winter here?\n/exit\n",
    );
    assert!(
        carried(&bodies, "Which ones winter here?", "Where do herons nest?"),
        "the CLI's turn carried the desktop's"
    );
    turn(&runtime, &id, Some("research"), "Thanks.");
    assert!(
        carried(&bodies, "Thanks.", "Which ones winter here?"),
        "the desktop's turn carried the CLI's"
    );
    let (_, raw) = call(
        &runtime,
        "GET",
        &scoped(&format!("{API}/sessions/{id}"), "research"),
        None,
    );
    assert_eq!(
        said_by(&parsed(&raw), "user"),
        ["Where do herons nest?", "Which ones winter here?", "Thanks."],
        "{raw}"
    );

    // The active profile is what it was, for the runtime and the CLI.
    assert_eq!(active(&home, &runtime), default);
}

# Conversation profiles and the account-integration contract

Owner decision (2026-11-04): `lightagent chat --profile X` is matched by
a conversation-scoped profile, not by the profile switch. A conversation
runs as the profile it is bound to, and the active (default) profile is
never changed by choosing one. This document records the local contract
(implemented in row 57) and the contract a later online-account stage
must keep. Online login and synchronization are not part of D7-D10.

## The local contract (implemented)

- **Binding.** A conversation is bound to one agent profile when it is
  created and is kept in that profile's own store,
  `profiles/<id>/sessions`, the store `chat --profile <id>` uses. The
  binding is the `profile` field of the saved session; it never changes.
- **Naming the profile.** Every conversation operation can name its
  profile: `?profile=` on `GET/POST /sessions`, `GET /sessions/search`,
  `GET/PATCH/DELETE /sessions/{id}` and `POST
  /sessions/{id}/attachments`, and `profile` in the `POST /runs` and `POST
  /sessions/{id}/regenerate` bodies. Unnamed, the profile the runtime
  serves, exactly as before. A conversation is found only under its own
  profile.
- **Resolution.** A run of the conversation is built from its profile
  through the run factory `lightagent chat` shares: persona, model, tool
  policy, durable memory (the profile's directory) and remote-credential
  grants (the profile's own). Nothing of the active profile is borrowed.
- **The active profile** changes only through `profile use` (CLI) or the
  desktop's profile switch (DESKTOP_ARCHITECTURE.md §7), never through a
  conversation's profile.
- **The desktop UI.** A Profile choice by the conversation list (shown
  when there is more than one profile) lists that profile's conversations
  and starts new ones as it. It is a per-viewer convenience kept in the
  page's storage, not a setting.

## Authorization: a profile id is a selector, never a credential

- **Local operator** (the desktop runtime's key, or an open loopback
  server): authorized as the operator first, by the host's key and the
  Host/Origin guard. It may then name any profile that exists in this
  home, as the CLI with access to the home may. A profile that does not
  exist is 404 and nothing is created; an invalid id is 400.
- **Multi-user mode** (identity on): a user's request that names a
  profile is authorized server-side (`authorize_profile`) against the
  user's grants, and a conversation is returned only if the user owns it;
  otherwise the answer is the same as for a conversation that does not
  exist. Holding, guessing or being sent a profile id or a conversation
  id grants nothing.

## Three identities, kept apart

| Identity | What it is | Local today | Never implies |
|---|---|---|---|
| Account | who acts (a person or a service) | `PrincipalId` in multi-user mode; the local operator otherwise | any profile |
| Agent profile | as which agent a run acts: persona, model, tools, memory, credential grants | `ProfileId` | an account, or ownership |
| Conversation | one transcript and its runs | `SessionId`, inside one profile's store; `owner` in multi-user mode | its profile's other conversations |

An account may be granted several profiles; a profile is used by an
account only through a grant; a conversation belongs to exactly one
profile and, in multi-user mode, one owner.

## The future cloud mapping (contract for the online stage)

Not implemented. The online stage must keep these rules:

1. **Keys.** A cloud conversation is addressed by (account, profile,
   conversation). Conversation ids are assigned by the server; a client
   never chooses an owner.
2. **Every request is authorized on the server**: authenticate the
   account; resolve its grants for the named profile; load the
   conversation only if its owner is that account and its profile is the
   named one; otherwise answer as for a missing conversation.
3. **Profiles map explicitly.** A local profile is linked to a cloud
   profile only by a user's explicit choice; ids are never matched by name
   alone, and an unlinked local profile is never uploaded.
4. **Synchronization** moves conversations of linked profiles only, with
   a revision per conversation (as `ConfigRevision` does for settings):
   a stale write is refused and offered for review, never merged
   silently.
5. **Credentials are never synchronized in plaintext.** Remote-credential
   grants stay per profile and per installation; the cloud stores at most
   that a grant exists. Provider keys stay with the installation.
6. **Local first.** Without an account, everything above works locally as
   it does today; signing out leaves local conversations local.
