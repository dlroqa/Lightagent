=== message
Separate signed from unsigned release runs; sign only in the environment

The release gate now decides `signing`: a manual run is unsigned unless
its new `signing` input is `signed`; a tag push always signs; any other
value is refused. In a signed run only the macOS and Windows desktop jobs
name the protected release-signing environment, so only they wait for its
reviewers and see its secrets; unsigned runs and Linux use no environment.

A signed run fails when a credential is missing (macOS: all six Apple
values; Windows: WINDOWS_SIGN_COMMAND), when Apple's notary service does
not accept a disk image, or when a signature does not verify. The .dmg
files are now signed, notarized and stapled themselves, and must carry
their ticket. On Windows the bundled runtime (lightagent-sidecar.exe) is
checked in the build and, with the app, in each installation: present
always, validly signed and timestamped in a signed run.

def signature(path):
    script = (f"$s = Get-AuthenticodeSignature -LiteralPath '{path}'; "
              "'{0}|{1}|{2}' -f $s.Status, $s.SignerCertificate.Subject, $s.TimeStamperCertificate.Subject")
    lines = sh(["powershell", "-NoProfile", "-Command", script])[1].strip().splitlines()
    status, signer, stamp = (lines[-1].split("|") + ["", ""])[:3] if lines else ("", "", "")
    return {"status": status.strip(), "signer": signer.strip() or None, "timestamp": stamp.strip() or None}


def installed_signatures(exe):
    """Authenticode of every executable the installation put beside the app."""
    folder = os.path.dirname(exe)
    files = {name: signature(os.path.join(folder, name)) for name in sorted(os.listdir(folder)) if name.lower().endswith(".exe")}
    present = all(name in files for name in REQUIRED_SIGNED)
    valid = all(files[name]["status"] == "Valid" and files[name]["timestamp"] for name in REQUIRED_SIGNED if name in files)
    return {"ok": present and (valid or not SIGNING_REQUIRED), "required": SIGNING_REQUIRED,
            "runtime_present": "lightagent-sidecar.exe" in files, "files": files}
