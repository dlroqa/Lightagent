=== message
Never leave the suite behind an open native picker

Desktop runs 41837688573 and its D8c successor: on macos-x64 the real
NSOpenPanel opened, System Events typed the path and the file was
selected, but the confirming Return did not land. A modal panel holds the
host's main thread, so the page could not answer, and every later scenario
timed out behind it. The outcome is now read with a short timeout; if none
shows, Return is pressed again, and as a last resort Escape cancels the
panel, so later scenarios run. What happened is recorded either way.
