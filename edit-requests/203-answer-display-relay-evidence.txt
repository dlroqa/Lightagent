=== message
Read each answer_display run live through the host relay

Tests only. The first answer_display runs read each run back by its saved
run_id after it ended, which the runtime does not keep as a live handle,
so the relay evidence was empty. Each display script now starts at a
gate: while the run is held there, the scenario takes its id from
GET /runs and subscribes through the host relay before releasing it, so
the events are recorded as the relay forwards them, the interrupted case's
resume included. After a reload, the conversation is found by its marker.
