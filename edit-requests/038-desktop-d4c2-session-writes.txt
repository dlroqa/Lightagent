Session writes: one locked writer for every process (#100)

Every session writer loaded a session whole, changed its copy and saved
it whole, with no lock that other processes respected. The terminal chat
and ACP saved a snapshot they had held for the whole conversation, so a
rename from the panel, or a turn from another client, was erased by the
next save; a second server on the same profile was not covered by the
in-process busy set either.

Now every writer takes one store lock (`sessions/.lock`, an exclusive OS
lock that every process takes) and changes the session as it is saved
now:
- `SessionStore::update(id, change)`: under the lock, re-read the session,
  apply the change, write atomically. A refused change, a failed write or
  an unreadable file writes nothing; a missing session stays missing, so
  nothing re-creates a deleted one.
- `SessionStore::apply(session, change)`: for a client holding a session
  open (the terminal chat, an ACP editor). The change applies to the
  saved state and the client's view becomes that state.
- `save` (new sessions) and `delete` take the same lock.
- The lock primitive is D4c's, factored into `paths::lock_exclusive`
  and shared by `ConfigStore`; its behaviour there is unchanged.

Converted: run admission (append), run completion and regenerate's swap
(`record_run_in_session`), PATCH /sessions/{id}, the terminal chat's
prompt, turn and approval writes, and ACP's prompt and completion. The
API does the locked work on the blocking pool. Run admission is still
the busy set, so this commit does not change admission, cancellation,
permission, ownership or profile isolation.

Tests: separate-process writers (this test binary run again) racing run
completion, regeneration, a provider failure and a cancellation while the
test holds the store lock; a failed record write; concurrent admission;
the desktop runtime's PATCH and the CLI's delete waiting on a lock held
by another process; ACP keeping a rename made while an editor holds the
session.

/// Why [`lock_exclusive`] returned no lock.
#[derive(Debug)]
pub enum LockError {
    /// Another holder kept the lock for the whole wait.
    Busy,
    /// The lock file could not be created, opened or locked.
    Io(io::Error),
}

/// Hold an exclusive OS lock on the file at `path`, creating the file and its
/// directory when missing. Every process takes the same lock, and the OS
/// releases it when the returned file is dropped or its process ends, so a
/// holder that crashed never leaves it stuck. Waits up to `wait` for another
/// holder, then reports [`LockError::Busy`].
pub fn lock_exclusive(
    path: &Path,
    wait: std::time::Duration,
) -> Result<std::fs::File, LockError> {
    if let Some(parent) = path.parent()
        && !parent.as_os_str().is_empty()
    {
        std::fs::create_dir_all(parent).map_err(LockError::Io)?;
    }
    let file = std::fs::OpenOptions::new()
        .create(true)
        .truncate(false)
        .write(true)
        .open(path)
        .map_err(LockError::Io)?;
    let deadline = std::time::Instant::now() + wait;
    loop {
        match file.try_lock() {
            Ok(()) => return Ok(file),
            Err(std::fs::TryLockError::WouldBlock) if std::time::Instant::now() < deadline => {
                std::thread::sleep(std::time::Duration::from_millis(10));
            }
            Err(std::fs::TryLockError::WouldBlock) => return Err(LockError::Busy),
            Err(std::fs::TryLockError::Error(err)) => return Err(LockError::Io(err)),
        }
    }
}

    /// The one way to change a saved session. Under the store's lock, read
    /// session `id` as it is saved now, apply `change`, and write it
    /// atomically. Nothing is written unless every step succeeds, so a
    /// refused change, a failed write or an unreadable file leaves the saved
    /// session exactly as it was. No other writer's change is lost, because
    /// each applies to what the last one wrote, and a missing session stays
    /// missing. Returns `change`'s value and the session as saved. With
    /// history off, nothing is written.
    pub fn update<T, E>(
        &self,
        id: &SessionId,
        change: impl FnOnce(&mut Session) -> Result<T, E>,
    ) -> Result<(T, Session), SessionUpdateError<E>> {
        let _lock = if self.keep_history {
            Some(self.lock().map_err(SessionUpdateError::Store)?)
        } else {
            None
        };
        let mut session = self.load(id).map_err(SessionUpdateError::Store)?;
        let value = change(&mut session).map_err(SessionUpdateError::Change)?;
        if self.keep_history {
            self.write(&session).map_err(SessionUpdateError::Store)?;
        }
        Ok((value, session))
    }

    /// For a client holding a session open, such as the terminal chat or an
    /// ACP editor: apply `change` to the session as saved now (see
    /// [`SessionStore::update`]) and make `session` that saved state, so the
    /// client also sees what other writers changed. A session not saved yet,
    /// or deleted meanwhile, is saved from `session` with the change, since
    /// it holds the client's whole conversation. On any other error the store
    /// is unchanged and `session` takes the change alone, as the client's
    /// view.
    pub fn apply<T>(
        &self,
        session: &mut Session,
        change: impl Fn(&mut Session) -> T,
    ) -> Result<T, StoreError> {
        match self.update(&session.id, |saved| Ok::<T, Infallible>(change(saved))) {
            Ok((value, saved)) => {
                *session = saved;
                Ok(value)
            }
            Err(error) => match error.into_store() {
                StoreError::NotFound(_) => {
                    let value = change(session);
                    self.save(session)?;
                    Ok(value)
                }
                error => {
                    change(session);
                    Err(error)
                }
            },
        }
    }

/// Why a session run was not admitted.
enum Refused {
    /// The session is missing or could not be read.
    Missing(String),
    /// The session belongs to another profile than the run's.
    ProfileMismatch,
    /// A regeneration named an answer that is not the session's latest.
    NotLatest,
    /// The prompt could not be saved.
    Unsaved(String),
}

impl IntoResponse for Refused {
    fn into_response(self) -> Response {
        match self {
            Self::Missing(error) => not_found(&error),
            Self::ProfileMismatch => bad_request("session profile does not match"),
            Self::NotLatest => (
                StatusCode::CONFLICT,
                Json(json!({"error": "only the latest answer can be regenerated"})),
            )
                .into_response(),
            Self::Unsaved(error) => internal(&error),
        }
    }
}

/// Whether a store error means the session cannot be read (missing,
/// malformed or damaged) rather than that it could not be written.
fn is_missing(error: &StoreError) -> bool {
    matches!(
        error,
        StoreError::NotFound(_) | StoreError::Unreadable { .. } | StoreError::MalformedId(_)
    )
}

/// Admit a run of session `id` for the profile `expected` (and `named`, when
/// the caller named one): the history the model sees and the prompt to run.
/// A new prompt is appended, under the store's lock, to the session as it is
/// saved now. A regeneration only reads: nothing is saved until its run has
/// finished with an answer (`record_run_in_session`).
fn admit(
    store: &SessionStore,
    id: &SessionId,
    expected: &str,
    named: Option<&str>,
    message: &str,
    replacing: Option<&str>,
    history_limit: usize,
) -> Result<(Vec<lightagent_core::provider::ProviderMessage>, String), Refused> {
    let check = |session: &Session| {
        if session.profile != expected || named.is_some_and(|value| value != session.profile) {
            Err(Refused::ProfileMismatch)
        } else {
            Ok(())
        }
    };
    let Some(run_id) = replacing else {
        return store
            .update(id, |session| {
                check(&*session)?;
                let history = model_history(session, message, history_limit);
                if session.messages.is_empty() && session.title == "agent session" {
                    session.title = session_title(message);
                }
                session.push_message(StoredMessage::new("user", message));
                Ok((history, message.to_owned()))
            })
            .map(|(admitted, _)| admitted)
            .map_err(|error| match error {
                SessionUpdateError::Change(refused) => refused,
                SessionUpdateError::Store(error) if is_missing(&error) => {
                    Refused::Missing(error.to_string())
                }
                SessionUpdateError::Store(error) => Refused::Unsaved(error.to_string()),
            });
    };
    let mut earlier = store
        .load(id)
        .map_err(|error| Refused::Missing(error.to_string()))?;
    check(&earlier)?;
    let prompt = take_latest_answer(&mut earlier, run_id).ok_or(Refused::NotLatest)?;
    // The model sees what preceded the prompt, as it did on the prompt's
    // first run.
    earlier.messages.pop();
    Ok((model_history(&earlier, &prompt, history_limit), prompt))
}

// --- session writes: one locked writer for every process (#100) ------------

/// A server state whose session store is in a directory the test knows, so
/// the test can hold the store's lock as another process's writer would.
fn state_with_store(factory: GateFactory) -> (AppState, std::path::PathBuf) {
    let mut state = app_state(AuthConfig::open());
    let dir = std::env::temp_dir().join(format!(
        "lightagent-api-writes-{}",
        lightagent_core::RunId::new().as_str()
    ));
    state.sessions = SessionStore::new(&dir);
    state.manager = RunManager::new(Arc::new(factory));
    (state, dir)
}

/// Hold the session store's write lock, as another process's writer would.
fn hold_store_lock(dir: &std::path::Path) -> std::fs::File {
    std::fs::create_dir_all(dir).unwrap();
    let lock = std::fs::OpenOptions::new()
        .create(true)
        .truncate(false)
        .write(true)
        .open(dir.join(".lock"))
        .unwrap();
    lock.lock().unwrap();
    lock
}

/// The writer process of the session-write tests: this test binary, run
/// again with `LIGHTAGENT_TEST_RENAME_*` naming a store, a session and a
/// title. It marks that it started, then renames the session through the
/// store, waiting for the store's lock as every writer does. Run any other
/// way it does nothing.
#[test]
#[ignore = "run only as the writer process of the session-write tests"]
fn rename_writer_process() {
    let (Ok(dir), Ok(id), Ok(title)) = (
        std::env::var("LIGHTAGENT_TEST_RENAME_DIR"),
        std::env::var("LIGHTAGENT_TEST_RENAME_ID"),
        std::env::var("LIGHTAGENT_TEST_RENAME_TITLE"),
    ) else {
        return;
    };
    let dir = std::path::PathBuf::from(dir);
    let id = lightagent_store::SessionId::parse(&id).unwrap();
    std::fs::write(dir.join("writer.started"), b"").unwrap();
    SessionStore::new(&dir)
        .update(&id, |session| {
            session.title = title;
            Ok::<(), std::convert::Infallible>(())
        })
        .unwrap();
}

/// Start the writer process renaming session `id` to `title`, while the test
/// holds the store's lock, and return once it is waiting for that lock.
fn rename_in_another_process(
    dir: &std::path::Path,
    id: &str,
    title: &str,
) -> std::process::Child {
    let started = dir.join("writer.started");
    let _ = std::fs::remove_file(&started);
    let mut child = std::process::Command::new(std::env::current_exe().unwrap())
        .args(["--exact", "rename_writer_process", "--ignored"])
        .env("LIGHTAGENT_TEST_RENAME_DIR", dir)
        .env("LIGHTAGENT_TEST_RENAME_ID", id)
        .env("LIGHTAGENT_TEST_RENAME_TITLE", title)
        .stdout(std::process::Stdio::null())
        .stderr(std::process::Stdio::null())
        .spawn()
        .unwrap();
    let deadline = std::time::Instant::now() + Duration::from_secs(30);
    while !started.exists() {
        assert!(
            child.try_wait().unwrap().is_none(),
            "the writer process ended before writing"
        );
        assert!(
            std::time::Instant::now() < deadline,
            "the writer process never started"
        );
        std::thread::sleep(Duration::from_millis(10));
    }
    std::thread::sleep(Duration::from_millis(300));
    assert!(
        child.try_wait().unwrap().is_none(),
        "the writer wrote while the store's lock was held"
    );
    child
}

/// Wait for the writer process to finish its write.
async fn finish(writer: std::process::Child) {
    let status = tokio::task::spawn_blocking(move || {
        let mut writer = writer;
        writer.wait().unwrap()
    })
    .await
    .unwrap();
    assert!(status.success(), "the writer process failed: {status}");
}

fn run_id(body: &str) -> String {
    serde_json::from_str::<serde_json::Value>(body).unwrap()["id"]
        .as_str()
        .unwrap()
        .to_owned()
}

/// Wait until run `run` reports `status`.
async fn ended(addr: &str, run: &str, status: &str) {
    loop {
        let (_, body) = http(
            addr,
            "GET",
            &format!("/api/lightagent/v1/runs/{run}"),
            &[],
            None,
        )
        .await;
        let value: serde_json::Value = serde_json::from_str(&body).unwrap_or_default();
        if value["status"] == status {
            return;
        }
        tokio::time::sleep(Duration::from_millis(10)).await;
    }
}

async fn start_session_run(addr: &str, id: &str, message: &str) -> (u16, String) {
    let payload = serde_json::json!({ "message": message, "session_id": id }).to_string();
    http(addr, "POST", "/api/lightagent/v1/runs", &[], Some(&payload)).await
}

fn transcript(session: &lightagent_store::Session) -> Vec<(String, String)> {
    session
        .messages
        .iter()
        .map(|message| (message.role.clone(), message.content.clone()))
        .collect()
}

fn pair(role: &str, content: &str) -> (String, String) {
    (role.to_owned(), content.to_owned())
}

async fn a_run_whose_record_cannot_be_written_leaves_the_saved_session_whole() {
    tokio::time::timeout(Duration::from_secs(60), async {
        let factory = GateFactory::new(GateMode::Answer);
        let (state, dir) = state_with_store(factory.clone());
        let store = state.sessions.clone();
        let busy = Arc::clone(&state.busy_sessions);
        let session = lightagent_store::Session::new("default", "Draft");
        store.save(&session).unwrap();

        assert_eq!(status, 202, "{body}");

            tokio::task::yield_now().await;
        }
        // The atomic write's temporary file cannot be created.
        let path = dir.join(format!("{id}.json"));
        let temporary = dir.join(format!("{id}.json.tmp"));

        assert_eq!(status, 202, "{body}");

        assert_eq!(
            transcript(&store.load(&session.id).unwrap()),
            [
                pair("user", "what time is it"),
                pair("user", "and now?"),
                pair("assistant", "The time is now.")
            ]
        );
        std::fs::remove_dir_all(&dir).ok();
    })
    .await
    .unwrap();

=== write crates/lightagent/tests/session_writes.rs
//! Session writes from separate processes: the desktop runtime and the CLI
//! take one lock on a profile's session store and change a session as it is
//! saved at that moment, so neither loses the other's change. A deletion is
//! ordered the same way, and no later write brings a deleted session back.

use std::fs::OpenOptions;
use std::io::{BufRead as _, BufReader, Read as _, Write as _};
use std::net::TcpStream;
use std::path::{Path, PathBuf};
use std::process::{Child, ChildStdin, Command, Stdio};
use std::sync::mpsc;
use std::time::{Duration, SystemTime, UNIX_EPOCH};

const KEY: &str = "5e4f30211203f4e5d6c7b8a99a8b7c6d5e4f30211203f4e5d6c7b8a99a8b7c6d";

struct Runtime {
    child: Child,
    _lifeline: ChildStdin,
    addr: String,
}

impl Drop for Runtime {
    fn drop(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
    }
}

fn scratch_home(label: &str) -> PathBuf {
    let nanos = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|elapsed| elapsed.as_nanos())
        .unwrap_or(0);
    let home = std::env::temp_dir().join(format!(
        "lightagent-session-writes-{label}-{}-{nanos}",
        std::process::id()
    ));
    std::fs::create_dir_all(&home).expect("home");
    home
}

fn start(home: &Path) -> Runtime {
    let mut child = Command::new(env!("CARGO_BIN_EXE_lightagent"))
        .args(["serve", "--desktop", "--host", "127.0.0.1", "--port", "0"])
        .env("LIGHTAGENT_HOME", home)
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .expect("start lightagent serve --desktop");
    let mut lifeline = child.stdin.take().expect("stdin");
    writeln!(lifeline, "{KEY}").expect("key");
    lifeline.flush().expect("flush");
    let stdout = child.stdout.take().expect("stdout");
    let (tx, rx) = mpsc::channel();
    std::thread::spawn(move || {
        let mut line = String::new();
        let _ = BufReader::new(stdout).read_line(&mut line);
        let _ = tx.send(line);
    });
    let line = rx.recv_timeout(Duration::from_secs(60)).expect("handshake");
    let handshake: serde_json::Value = serde_json::from_str(&line).expect("handshake JSON");
    let addr = handshake["addr"].as_str().expect("addr").to_owned();
    Runtime {
        child,
        _lifeline: lifeline,
        addr,
    }
}

/// One authenticated request to the runtime at `addr`: the status and the
/// body's JSON.
fn call(addr: &str, method: &str, path: &str, body: Option<&str>) -> (u16, serde_json::Value) {
    let mut stream = TcpStream::connect(addr).expect("connect");
    stream
        .set_read_timeout(Some(Duration::from_secs(20)))
        .expect("timeout");
    let body = body.unwrap_or("");
    let head = format!(
        "{method} {path} HTTP/1.1\r\nHost: {addr}\r\nAuthorization: Bearer {KEY}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        body.len()
    );
    stream.write_all(head.as_bytes()).expect("send");
    let mut response = String::new();
    let _ = stream.read_to_string(&mut response);
    let status = response
        .split_whitespace()
        .nth(1)
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    let json = response
        .split_once("\r\n\r\n")
        .and_then(|(_, body)| serde_json::from_str(body).ok())
        .unwrap_or(serde_json::Value::Null);
    (status, json)
}

/// Where the runtime saved session `id`.
fn session_file(home: &Path, id: &str) -> PathBuf {
    std::fs::read_dir(home.join("profiles"))
        .expect("profiles")
        .flatten()
        .map(|entry| entry.path().join("sessions").join(format!("{id}.json")))
        .find(|path| path.is_file())
        .expect("the session file")
}

fn read_json(path: &Path) -> serde_json::Value {
    serde_json::from_slice(&std::fs::read(path).expect("read")).expect("session JSON")
}

#[test]
fn a_rename_in_the_runtime_and_a_cli_delete_wait_for_another_processs_lock() {
    let home = scratch_home("lock");
    let runtime = start(&home);
    let (status, created) = call(&runtime.addr, "POST", "/api/lightagent/v1/sessions", Some("{}"));
    assert_eq!(status, 201, "{created}");
    let id = created["id"].as_str().expect("id").to_owned();
    let path = session_file(&home, &id);
    let lock = OpenOptions::new()
        .create(true)
        .truncate(false)
        .write(true)
        .open(path.with_file_name(".lock"))
        .expect("lock file");

    // A rename from the desktop runtime waits while another process holds the
    // lock, then keeps the turn that process wrote inside it.
    lock.lock().expect("hold the session store's lock");
    let rename = {
        let addr = runtime.addr.clone();
        let route = format!("/api/lightagent/v1/sessions/{id}");
        std::thread::spawn(move || {
            call(&addr, "PATCH", &route, Some(r#"{"title":"Renamed in Settings"}"#))
        })
    };
    std::thread::sleep(Duration::from_millis(800));
    assert!(
        !rename.is_finished(),
        "the runtime wrote while another process held the lock"
    );
    let mut value = read_json(&path);
    value["messages"] = serde_json::json!([
        { "role": "user", "content": "from the terminal" },
        { "role": "assistant", "content": "kept" }
    ]);
    std::fs::write(&path, serde_json::to_vec_pretty(&value).expect("JSON")).expect("write");
    lock.unlock().expect("release");
    let (status, renamed) = rename.join().expect("join");
    assert_eq!(status, 200, "{renamed}");
    assert_eq!(renamed["message_count"], 2);
    let saved = read_json(&path);
    assert_eq!(saved["title"], "Renamed in Settings");
    assert_eq!(saved["messages"][1]["content"], "kept");

    // A deletion from the CLI waits the same way, and a later write from the
    // runtime does not bring the session back.
    lock.lock().expect("hold the lock again");
    let delete = Command::new(env!("CARGO_BIN_EXE_lightagent"))
        .args(["sessions", "delete", &id])
        .env("LIGHTAGENT_HOME", &home)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .expect("start the CLI deletion");
    let mut delete = delete;
    std::thread::sleep(Duration::from_millis(800));
    assert!(
        delete.try_wait().expect("poll").is_none(),
        "the CLI deleted while another process held the lock"
    );
    assert!(path.is_file());
    lock.unlock().expect("release");
    let output = delete.wait_with_output().expect("wait");
    assert!(
        output.status.success(),
        "{}",
        String::from_utf8_lossy(&output.stderr)
    );
    assert!(!path.exists());
    let (status, _) = call(
        &runtime.addr,
        "PATCH",
        &format!("/api/lightagent/v1/sessions/{id}"),
        Some(r#"{"title":"Too late"}"#),
    );
    assert_eq!(status, 404);
    assert!(!path.exists(), "a write after the deletion re-created the session");
}
