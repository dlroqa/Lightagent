=== message
Fix what the first native runs found: labels, contrast and the suite's own matching

The first runs on all four targets (desktop run 41822033959) drove the
real WebViews through most scenarios. They found two product defects and
several harness mistakes:

- Settings had four number and text inputs whose visible label was not
  tied to the input (axe `label`, critical, on every target). Each label
  now names its input through useId.
- The avatar's white on teal (3.2:1) and the chat list's section label
  failed contrast (axe `color-contrast`, serious): a darker teal and the
  muted text token.
- The suite matched conversation titles with their trailing full stop,
  which titles drop; read the run's answer as one sentence where the UI
  shows the text before a pause separately; and could press Send before
  the composer was live. Sending now confirms the message reached the
  conversation and tries once more if not.
- A crash that leaves the next send unanswered now records the page, the
  host's status and the runtime's recent output (new driver op `logs`),
  and the window is brought to the front through the OS on Windows and
  macOS before OS key presses.

    def send(self, message):
        """Type and send `message`, and confirm it reached the conversation;
        a send pressed before the composer was live is tried once more."""
        for attempt in (1, 2):
            reached = self.js(T("""
              const box = await need("the composer", () => all("textbox", "Ask Lightagent").find((el) => !el.disabled));
              fill(box, $MESSAGE);
              const button = await need("Send", () => all("button").filter((el) => /^(Send message|Queue steer)$/.test(nameOf(el)) && !el.disabled).pop());
              press(button);
              return !!(await until(() => [...document.querySelectorAll('[aria-label="Your message"]')]
                .some((el) => el.textContent.includes($MESSAGE)), 10000));""", MESSAGE=message), 40)
            if reached:
                return
            self.shot(f"send-not-shown-{attempt}")
        raise harness.HostError(f"the message never reached the conversation; the page ends: {self.js('return text().slice(-400);')!r}")
