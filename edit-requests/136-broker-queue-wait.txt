=== message
Broker: wait for a runner and for the run separately, with diagnostics

actions.status waited for a run with a single deadline that counted the
time a dispatched run sat queued for a hosted runner. Under load
(2026-11-03), children of the subagents workflow waited 11-19 minutes for a
runner. The live broker checks then read them as still_running after 600
s and failed, though every child, once it ran, passed or failed exactly as
intended.

The wait now has two bounded phases and an overall cap:
- queue: until the run leaves requested/queued/pending/waiting, at most
  ActionsPolicy::queue_wait (config platform.github_actions.queue_wait_secs,
  default 600, at most 3600);
- run: from when the run is first seen executing, at most max_wait
  (max_wait_secs, at most 900, as before);
- overall: the call's wait_seconds, at most queue_wait + max_wait.
A run that has not completed is still_queued or still_running, never
passed. The report adds `wait`: the outcome (completed, queue_timeout,
run_timeout, overall_timeout, cancelled, not_waited), the milliseconds
queued, running and in all, and the three limits. A cancelled call stops
at once and says so.

Tests: a stand-in run whose reads go through staged statuses covers queued
→ running → passed, a queue that never yields a runner, an execution
timeout, cancellation, an unexpected failure and a startup failure, no
wait, and the overall cap.

The live checks allow the observed queue (30 min) and 10 min of execution.
The coder check dispatches both verifications before waiting, so they queue
together, and a run the check gave up on is cancelled with its diagnostics
printed. The broker job's timeout grows to 95 minutes to fit these
deadlines.

/// Read a run, waiting up to `wait` in all for it to complete: at most
/// `queue_wait` for it to get a runner, and at most `max_wait` from when it
/// is first seen executing. What was waited for, and why the wait ended, is
/// reported with the run.
async fn status(
    actions: &ActionsContext,
    run_id: u64,
    wait: Duration,
    ctx: &ToolCtx,
) -> Result<Value, String> {
    let policy = &actions.policy;
    let begun = Instant::now();
    let mut running_since: Option<Instant> = None;
    let mut run = read_run(actions, run_id).await?;
    let completed = |run: &Value| run.get("status").and_then(Value::as_str) == Some("completed");
    let queued = |run: &Value| {
        run.get("status")
            .and_then(Value::as_str)
            .is_some_and(|status| NOT_STARTED.contains(&status))
    };
    let outcome = loop {
        if completed(&run) {
            break "completed";
        }
        let now = Instant::now();
        if running_since.is_none() && !queued(&run) {
            running_since = Some(now);
        }
        if wait.is_zero() {
            break "not_waited";
        }
        if now >= begun + wait {
            break "overall_timeout";
        }
        match running_since {
            None if now >= begun + policy.queue_wait => break "queue_timeout",
            Some(since) if now >= since + policy.max_wait => break "run_timeout",
            _ => {}
        }
        ctx.report(ToolProgress::stage(if running_since.is_some() {
            "waiting for the run to finish"
        } else {
            "waiting for the run to get a runner"
        }));
        if !pause(ctx, policy.poll_interval).await {
            break "cancelled";
        }
        run = read_run(actions, run_id).await?;
    };
    let ended = Instant::now();
    let jobs = read_jobs(actions, run_id).await?;
    let conclusion = run.get("conclusion").and_then(Value::as_str);
    let verdict = match (completed(&run), conclusion) {
        (true, Some("success")) => "passed",
        (true, Some("failure")) => "failed",
        (true, Some("cancelled")) => "cancelled",
        (true, _) => "not_passed",
        (false, _) if queued(&run) => "still_queued",
        (false, _) => "still_running",
    };
    let millis = |duration: Duration| u64::try_from(duration.as_millis()).unwrap_or(u64::MAX);
    let queued_for = running_since.unwrap_or(ended).duration_since(begun);
    let running_for = running_since
        .map(|since| ended.duration_since(since))
        .unwrap_or_default();
    let waited = json!({
        "outcome": outcome,
        "waited_ms": millis(ended.duration_since(begun)),
        "queued_ms": millis(queued_for),
        "running_ms": millis(running_for),
        "limits_ms": {
            "overall": millis(wait),
            "queue": millis(policy.queue_wait),
            "run": millis(policy.max_wait),
        },
    });

        500,

            ("queued", None),

    assert!(
        status["wait"]["queued_ms"].as_u64().is_some_and(|ms| ms > 0),
        "{status}"

    assert!(
        status["wait"]["running_ms"].as_u64().is_some_and(|ms| ms > 0),
        "{status}"
    );

}

/// In a live check, a run the wait gave up on is cancelled so it does not
/// hold a runner after the check has failed; its wait is printed.
async fn cancel_unfinished(ctx: &ToolCtx, status: &Value) {
    if matches!(
        status["verdict"].as_str(),
        Some("still_queued" | "still_running")
    ) {
        let args = json!({ "run_id": status["run_id"] });
        let cancelled = ActionsCancel::new().call(&args, ctx).await;
        println!(
            "EVIDENCE cancelled unfinished run {}: {} (wait {})",
            status["run_id"], cancelled.content, status["wait"]
        );
    }
}
