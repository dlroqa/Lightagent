=== message
Row 44: a new credential key needs no configured one

Found by the render harness (check run 41591038080, job 125767579488):
`remote-credential keygen <file>` loaded the configured key before doing
anything, so with LIGHTAGENT_CREDENTIAL_KEY_FILE already naming the file
to create it failed ("credential storage is unavailable (NotFound)").
The same held for any missing or unusable configured key, which is when
a new key is needed; and the API path had the same order.

- keygen (CLI and API) no longer loads the configured key; every other
  command still fails closed on an unusable one.
- render-panel.sh and runs.py create the key file before naming it.
- desktop_remote_credentials.rs: with an unusable configured key, keygen
  over the API and by the CLI still create a key file, and the vault
  stays refused.
