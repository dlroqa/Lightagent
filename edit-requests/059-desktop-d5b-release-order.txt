=== message
D5b: release the run lease before the busy entry

The lease was released when the recorder returned, just after it removed
the session's busy entry. A caller that saw the busy entry go and started
the next turn at once could still find the lease held for a moment and get
409: the existing regenerate test did exactly that on two platforms (check
run 41402975656). Every path now releases the lease first, so a session
free in this process is free in every process: the recorder after saving
the run, a refused admission, an admission that could not be read, and a
supervised start that was denied.
