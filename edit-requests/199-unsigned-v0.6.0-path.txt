=== message
Give v0.6.0 its owner-approved unsigned release path, and one release per tag

The owner approved unsigned macOS and Windows installers for v0.6.0 only.
The release gate now holds that approval as an exact list of tags
(UNSIGNED_RELEASES="v0.6.0"): such a tag publishes unsigned, from its own
tag push only, so its desktop jobs never use release-signing. A manual
publishing run on it is refused, so the two cannot race. Every other tag
still publishes signed, and a manual unsigned publication of any other tag
is refused. Dry runs are unchanged.

release.yml runs one release at a time per ref (concurrency, never
cancelling), and the publish job refuses to draft when a release for the
tag already exists, verifies SHA256SUMS against the assets, and drafts
with docs/releases/<tag>.md as the body.

The release notes state that the installers are unsigned, what Gatekeeper
reported, the effect of not marking the release Latest on
`lightagent update`, the tested and declared OS versions, and how to check
the files.

def gate(event, ref_type, ref_name, dry_run, signing="", unsigned=None):
    """`unsigned` replaces the gate's list of tags approved to publish unsigned; None keeps the shipped list."""
    env = {k: v for k, v in os.environ.items()
           if k not in ("EVENT", "REF_TYPE", "REF_NAME", "DRY_RUN", "SIGNING", "RELEASE_GATE_UNSIGNED_RELEASES")}
    env.update(EVENT=event, REF_TYPE=ref_type, REF_NAME=ref_name, DRY_RUN=dry_run, SIGNING=signing)
    if unsigned is not None:
        env["RELEASE_GATE_UNSIGNED_RELEASES"] = unsigned

# Lightagent 0.6.0

> **The macOS and Windows Desktop installers in this release are not code-signed.**
> The macOS packages are not signed with a Developer ID or notarized by
> Apple, and the Windows installers carry no Authenticode signature. Your
> system will warn you or block the app at first (see "Before you install").
> Check every download against `SHA256SUMS` before you open it.

0.6.0 is the first release with **Lightagent Desktop**, a native app for macOS
(Apple silicon and Intel), Windows x64 and Linux x64. It starts and owns its
own bundled runtime and reaches every applicable CLI capability (222 of 222)
through the same operations the CLI and the API use: conversations,
profiles, providers and models, tools, extensions and MCP servers, skills,
memory, knowledge, workers, identity, remote credentials, diagnostics and
setup. The CLI keeps its name and its archives.

## This release is not marked Latest

The previous Latest release stays Latest. `lightagent update` (and the
Desktop's "Check for updates") read GitHub's latest release, so:

- On 0.5.x, `lightagent update` reports that you are up to date and does
  **not** install 0.6.0. To use 0.6.0, download it from this page.
- On 0.6.0, the update check reports 0.6.0 as up to date (the latest
  release it reads is older). Nothing is downgraded.

## Check the download first

```
# macOS: compare with the line for the file in SHA256SUMS
shasum -a 256 Lightagent_0.6.0_aarch64.dmg

# Linux, in the download folder
sha256sum -c SHA256SUMS --ignore-missing

# Windows (PowerShell): compare with the line for the file in SHA256SUMS
Get-FileHash .\Lightagent_0.6.0_x64-setup.exe -Algorithm SHA256
```

Linux packages are not signed either. Their integrity check is `SHA256SUMS`,
as for every earlier Lightagent release.

## Before you install

- **macOS.** Gatekeeper rejects both apps. On GitHub's macOS 15 runners, a
  quarantined copy of each .dmg, and the app copied out of it, were
  assessed as rejected: "no usable signature" (Intel), and "code has no
  resources but signature indicates they must be present" (Apple silicon,
  which carries only the build's ad-hoc signature). Expect macOS to refuse
  to open the app, and on Apple silicon possibly to call it damaged.
  - **Normal route:** open it once, then System Settings › Privacy &
    Security › *Open Anyway*.
  - **If that option does not appear:** after copying the app to
    Applications, run
    `xattr -dr com.apple.quarantine /Applications/Lightagent.app`, and do
    this only for a file whose checksum you have verified.
- **Windows.** The setup .exe, the .msi, the app and its bundled runtime
  have no Authenticode signature (Windows reports `NotSigned`). Microsoft
  Defender SmartScreen is expected to show "Windows protected your PC" for
  a downloaded unsigned installer: choose *More info*, then *Run anyway*.
  GitHub's Windows runners cannot show SmartScreen, so this prompt was not
  observed there.
- **Your data.** The Desktop keeps its data in the same Lightagent home as
  the CLI (`~/.lightagent`). Installing, reinstalling and uninstalling the
  app leave it in place.
- **Updates.** The Desktop does not update itself. Install a newer version
  from its installer.

## What was tested

Every installer was installed, launched, installed again over itself
(same version), and uninstalled on a GitHub-hosted runner of its platform.
The user's data (a profile, settings, a conversation with an attachment, a
memory, a knowledge source, a provider key and a sealed credential) was
checked after each step and was unchanged.

| Package | Tested on | Declared minimum (not tested at that version) |
| --- | --- | --- |
| macOS, Apple silicon | macOS 15.8 | macOS 11.0 |
| macOS, Intel | macOS 15.7 | macOS 10.14 |
| Windows x64 | Windows Server 2025 and Windows Server 2022 | none declared; needs the WebView2 Runtime (Windows 10 or 11) |
| Linux x64 | Ubuntu 22.04 (glibc 2.35) | glibc 2.34, `libwebkit2gtk-4.1-0` |

Windows 10 and Windows 11 client editions and macOS versions before 15
were not tested by the automated runs.

## Licenses and notices

Each package carries `THIRD_PARTY_NOTICES.txt` and `LICENSE.txt`:

- **macOS:** inside `Lightagent.app/Contents/Resources`.
- **Windows:** beside the installed app.
- **Linux:** in the package.

The notices name every third-party component at its exact version with its
license text. Where a crate was published without one, the text comes from
its upstream repository at the commit that version was published from.
`desktop-mpl-sources-0.6.0.tar.gz` is the exact, unmodified source of the
five MPL-2.0 components the Desktop contains (cssparser 0.37.0,
cssparser-macros 0.7.1, dtoa-short 0.3.5, option-ext 0.2.0, selectors
0.38.0), with their checksums and the MPL-2.0 text. Lightagent is licensed
under the Apache License 2.0.
