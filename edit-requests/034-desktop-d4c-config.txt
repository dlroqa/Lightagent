Desktop D4c: one locked, revision-checked configuration writer

Every config write now goes through `ConfigStore::update`: an exclusive OS
lock on `config.json.lock` (std file locking; every process, no new
dependency), a fresh read, an optional expected revision (SHA-256 of the
file's bytes) refused as a conflict when stale, the change, validation,
and an atomic write. A lock held past the wait is `Busy`, never a hang.

Converted writers: `lightagent config set`, `init`, extension install and
enable/disable, chat onboarding, `setup` (revision-checked: it refuses to
save over a change made while it was open), and `PUT /settings` (a locked
read-modify-write; `expected_revision` makes a stale save a 409). The key
rules of `config get|set` move to `lightagent_core::config_keys`, so the
CLI and the new routes accept and refuse exactly the same keys and values:
GET /config (path, revision, redacted config), GET /config/{key},
PUT /config/{key} (with `expected_revision`, 409 when stale).

Settings sends the revision it loaded and reloads on 409; an advanced
editor reads and sets keys through the new routes. Contract operations
config.show/get/set, and inventory/parity rows (backend, counted through
cli.config.*) are added.

Tests: core unit tests (revisions, stale update, failed and invalid
changes, waiting for the lock and reading fresh, Busy); a hosted
cross-process test that holds the lock while the CLI waits and keeps a
change made inside it; CLI/API equivalence on one home (values, errors);
stale 409 for /config and /settings; secret redaction across CLI and API;
and a browser check of the editor's write, stale refusal and invalid
value.

/// How long a writer waits for another writer's lock before reporting
/// [`ConfigError::Busy`].
const LOCK_WAIT: std::time::Duration = std::time::Duration::from_secs(5);

/// A revision of the config file: `sha256:` and the hash of its exact bytes,
/// or `absent` before the file exists. A writer names the revision it read;
/// [`ConfigStore::update`] refuses a write made against any other.
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ConfigRevision(String);

impl ConfigRevision {
    fn of(bytes: Option<&[u8]>) -> Self {
        use sha2::{Digest as _, Sha256};
        use std::fmt::Write as _;
        let Some(bytes) = bytes else {
            return Self("absent".to_owned());
        };
        let mut text = String::from("sha256:");
        for byte in Sha256::digest(bytes).iter() {
            let _ = write!(text, "{byte:02x}");
        }
        Self(text)
    }

    /// A revision a client sends back, exactly as it was given out.
    pub fn parse(value: &str) -> Self {
        Self(value.trim().to_owned())
    }

    pub fn as_str(&self) -> &str {
        &self.0
    }
}

/// Why [`ConfigStore::update`] wrote nothing.
#[derive(Debug)]
pub enum UpdateError<E> {
    /// The change itself refused, with its own error.
    Change(E),
    /// The store refused: a stale revision, a busy lock, an invalid result,
    /// or a file that could not be read or written.
    Store(ConfigError),
}

impl UpdateError<std::convert::Infallible> {
    /// The store's error: a change that cannot fail has no other.
    pub fn into_store(self) -> ConfigError {
        match self {
            Self::Store(error) => error,
            Self::Change(never) => match never {},
        }
    }
}

impl<E: std::fmt::Display> std::fmt::Display for UpdateError<E> {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Change(error) => error.fmt(f),
            Self::Store(error) => error.fmt(f),
        }
    }
}

    /// The one way to change the config. Under the config lock, read the file
    /// as it is now, refuse when `expected` names another revision, apply
    /// `change`, validate, and write atomically. Nothing is written unless
    /// every step succeeds, and no other writer's change is lost: each one
    /// applies to what the last one wrote. Returns `change`'s value and the
    /// new revision.
    pub fn update<T, E>(
        &self,
        expected: Option<&ConfigRevision>,
        change: impl FnOnce(&mut Config) -> Result<T, E>,
    ) -> Result<(T, ConfigRevision), UpdateError<E>> {
        let _lock = self.lock().map_err(UpdateError::Store)?;
        let (mut config, current) = self.load_with_revision().map_err(UpdateError::Store)?;
        if let Some(expected) = expected
            && *expected != current
        {
            return Err(UpdateError::Store(ConfigError::Conflict {
                expected: expected.0.clone(),
                current: current.0,
            }));
        }
        let value = change(&mut config).map_err(UpdateError::Change)?;
        let revision = self.write(&config).map_err(UpdateError::Store)?;
        Ok((value, revision))
    }

    /// Hold the config's write lock: an exclusive OS lock on `<config>.lock`,
    /// which every process takes. Waits up to the store's lock wait.
    fn lock(&self) -> Result<std::fs::File, ConfigError> {
        let mut name = self
            .path
            .file_name()
            .map(std::ffi::OsStr::to_os_string)
            .unwrap_or_default();
        name.push(".lock");
        let path = self.path.with_file_name(name);
        let unwritable = |err: std::io::Error| ConfigError::Unwritable {
            path: path.clone(),
            reason: err.to_string(),
        };
        if let Some(parent) = path.parent()
            && !parent.as_os_str().is_empty()
        {
            std::fs::create_dir_all(parent).map_err(&unwritable)?;
        }
        let file = std::fs::OpenOptions::new()
            .create(true)
            .truncate(false)
            .write(true)
            .open(&path)
            .map_err(&unwritable)?;
        let deadline = std::time::Instant::now() + self.lock_wait;
        loop {
            match file.try_lock() {
                Ok(()) => return Ok(file),
                Err(std::fs::TryLockError::WouldBlock) if std::time::Instant::now() < deadline => {
                    std::thread::sleep(std::time::Duration::from_millis(10));
                }
                Err(std::fs::TryLockError::WouldBlock) => {
                    return Err(ConfigError::Busy {
                        path: self.path.clone(),
                    });
                }
                Err(std::fs::TryLockError::Error(err)) => return Err(unwritable(err)),
            }
        }
    }

/// Parse an optional string key: an empty value clears it.
/// `jev-1.13.0=0.8,jev-1.14.0=0.85`; an empty value clears every entry.
fn parse_version_thresholds(
    value: &str,
) -> Result<std::collections::BTreeMap<String, f32>, String> {
    value
        .split(',')
        .map(str::trim)
        .filter(|entry| !entry.is_empty())
        .map(|entry| {
            let (version, threshold) = entry
                .split_once('=')
                .ok_or_else(|| format!("{entry:?} must be written version=threshold"))?;
            let threshold = threshold
                .trim()
                .parse::<f32>()
                .map_err(|_| format!("{entry:?} needs a numeric threshold"))?;
            Ok((version.trim().to_owned(), threshold))
        })
        .collect()
}

fn parse_opt_string(value: &str) -> Option<String> {
    let trimmed = value.trim();
    if trimmed.is_empty() {
        None
    } else {
        Some(trimmed.to_string())
    }
}

/// Parse an optional `u32` key: an empty value clears it.
fn parse_opt_u32(value: &str) -> Result<Option<u32>, String> {
    let trimmed = value.trim();
    if trimmed.is_empty() {
        return Ok(None);
    }
    trimmed
        .parse::<u32>()
        .map(Some)
        .map_err(|_| format!("expected a non-negative integer, got '{value}'"))
}

fn parse_u32(value: &str, key: &str) -> Result<u32, String> {
    value
        .trim()
        .parse::<u32>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

fn parse_usize(value: &str, key: &str) -> Result<usize, String> {
    value
        .trim()
        .parse::<usize>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

fn parse_u64(value: &str, key: &str) -> Result<u64, String> {
    value
        .trim()
        .parse::<u64>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

/// Parse a boolean config value, accepting the usual spellings.
fn parse_bool(value: &str) -> Result<bool, String> {
    match value.trim().to_ascii_lowercase().as_str() {
        "true" | "1" | "yes" | "on" => Ok(true),
        "false" | "0" | "no" | "off" => Ok(false),
        _ => Err(format!("expected a boolean, got '{value}'")),
    }
}

/// Parse an optional string key: an empty value clears it.
/// `jev-1.13.0=0.8,jev-1.14.0=0.85`; an empty value clears every entry.
fn parse_version_thresholds(
    value: &str,
) -> Result<std::collections::BTreeMap<String, f32>, String> {
    value
        .split(',')
        .map(str::trim)
        .filter(|entry| !entry.is_empty())
        .map(|entry| {
            let (version, threshold) = entry
                .split_once('=')
                .ok_or_else(|| format!("{entry:?} must be written version=threshold"))?;
            let threshold = threshold
                .trim()
                .parse::<f32>()
                .map_err(|_| format!("{entry:?} needs a numeric threshold"))?;
            Ok((version.trim().to_owned(), threshold))
        })
        .collect()
}

fn parse_opt_string(value: &str) -> Option<String> {
    let trimmed = value.trim();
    if trimmed.is_empty() {
        None
    } else {
        Some(trimmed.to_string())
    }
}

/// Parse an optional `u32` key: an empty value clears it.
fn parse_opt_u32(value: &str) -> Result<Option<u32>, String> {
    let trimmed = value.trim();
    if trimmed.is_empty() {
        return Ok(None);
    }
    trimmed
        .parse::<u32>()
        .map(Some)
        .map_err(|_| format!("expected a non-negative integer, got '{value}'"))
}

fn parse_u32(value: &str, key: &str) -> Result<u32, String> {
    value
        .trim()
        .parse::<u32>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

fn parse_usize(value: &str, key: &str) -> Result<usize, String> {
    value
        .trim()
        .parse::<usize>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

fn parse_u64(value: &str, key: &str) -> Result<u64, String> {
    value
        .trim()
        .parse::<u64>()
        .map_err(|_| format!("{key} expects a non-negative integer, got '{value}'"))
}

/// Parse a boolean config value, accepting the usual spellings.
fn parse_bool(value: &str) -> Result<bool, String> {
    match value.trim().to_ascii_lowercase().as_str() {
        "true" | "1" | "yes" | "on" => Ok(true),
        "false" | "0" | "no" | "off" => Ok(false),
        _ => Err(format!("expected a boolean, got '{value}'")),
    }
}

async fn get_config(State(state): State<Arc<AppState>>, headers: HeaderMap) -> Response {
    if let Some(rejection) = deny(&state, &headers, Scope::Admin) {
        return rejection;
    }
    let Some(store) = &state.config_store else {
        return internal("Lightagent settings are unavailable in this embedding");
    };
    match store.load_with_revision() {
        Ok((config, revision)) => Json(json!({
            "path": store.path().display().to_string(),
            "revision": revision.as_str(),
            "config": config.redacted_json(),
        }))
        .into_response(),
        Err(error) => config_error(error),
    }
}

/// `lightagent config get <key>`: the same keys, the same redaction.
async fn get_config_key(
    State(state): State<Arc<AppState>>,
    headers: HeaderMap,
    Path(key): Path<String>,
) -> Response {
    if let Some(rejection) = deny(&state, &headers, Scope::Admin) {
        return rejection;
    }
    let Some(store) = &state.config_store else {
        return internal("Lightagent settings are unavailable in this embedding");
    };
    match store.load_with_revision() {
        Ok((config, revision)) => match lightagent_core::config_keys::get_key(&config, &key) {
            Some(value) => {
                Json(json!({ "key": key, "value": value, "revision": revision.as_str() }))
                    .into_response()
            }
            None => (
                StatusCode::NOT_FOUND,
                Json(json!({ "error": format!("unknown or unreadable config key '{key}'") })),
            )
                .into_response(),
        },
        Err(error) => config_error(error),
    }
}

/// `lightagent config set <key> <value>`, the same locked write. With
/// `expected_revision`, only when nothing changed since it was read.
async fn set_config_key(
    State(state): State<Arc<AppState>>,
    headers: HeaderMap,
    Path(key): Path<String>,
    Json(body): Json<ConfigWrite>,
) -> Response {
    if let Some(rejection) = deny(&state, &headers, Scope::Admin) {
        return rejection;
    }
    let Some(store) = &state.config_store else {
        return internal("Lightagent settings are unavailable in this embedding");
    };
    let expected = body.expected_revision.as_deref().map(ConfigRevision::parse);
    let written = store.update(expected.as_ref(), |config| {
        lightagent_core::config_keys::set_key(config, &key, &body.value)?;
        Ok::<_, String>(lightagent_core::config_keys::get_key(config, &key).unwrap_or_default())
    });
    match written {
        Ok((value, revision)) => {
            Json(json!({ "key": key, "value": value, "revision": revision.as_str() }))
                .into_response()
        }
        Err(UpdateError::Change(message)) => bad_request(&message),
        Err(UpdateError::Store(error)) => config_error(error),
    }
}

function message(cause: unknown): string {

/**
 * The CLI's `lightagent config path|show|get|set`, on the same file: the
 * server reads and writes it with the same key rules, under the same lock.
 * A write names the revision it was made against; if the file changed in
 * the meantime it is refused, nothing is written, and the editor reloads.
 */
export function ConfigEditorCard() {
  const keyId = useId();
  const valueId = useId();
  const [view, setView] = useState<ConfigView | null>(null);
  const [loadError, setLoadError] = useState<string | null>(null);
  const [key, setKey] = useState("");
  const [value, setValue] = useState("");
  const [formError, setFormError] = useState<string | null>(null);
  const [notice, setNotice] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  const load = useCallback(async () => {
    try {
      setView(await agentApi.config());
      setLoadError(null);
    } catch (cause) {
      setLoadError(message(cause));
    }
  }, []);

  useEffect(() => {
    void load();
  }, [load]);

  async function read() {
    const name = key.trim();
    if (!name) {
      setFormError("Enter a key, such as agent.max_turns.");
      return;
    }
    setBusy(true);
    setFormError(null);
    setNotice(null);
    try {
      const current = await agentApi.configKey(name);
      setValue(current.value);
      setNotice(`${current.key} = ${current.value || "(empty)"}`);
    } catch (cause) {
      setFormError(message(cause));
    } finally {
      setBusy(false);
    }
  }

  async function write(event: FormEvent) {
    event.preventDefault();
    const name = key.trim();
    if (!name || !view) {
      setFormError("Enter a key, such as agent.max_turns.");
      return;
    }
    setBusy(true);
    setFormError(null);
    setNotice(null);
    try {
      const saved = await agentApi.setConfigKey(name, value, view.revision);
      setNotice(`Set ${saved.key} = ${saved.value || "(empty)"}. New runs use it.`);
      await load();
    } catch (cause) {
      const text = cause instanceof Error ? cause.message : String(cause);
      if (text.startsWith("409:")) {
        setFormError("The configuration changed since it was loaded (another window, the CLI or the desktop app). Nothing was written; the current configuration is loaded now. Check it, then set the key again.");
        await load();
      } else {
        setFormError(message(cause));
      }
    } finally {
      setBusy(false);
    }
  }

  return (
    <Card title="Advanced configuration">
      <p className="card__note">
        The keys of <code>lightagent config get</code> and <code>set</code>, on the same file
        {view ? <>: <code>{view.path}</code></> : null}. Secrets are never shown.
      </p>
      {loadError && (
        <p className="config-editor__error" role="alert">
          The configuration could not be loaded: {loadError}
        </p>
      )}
      <form className="config-editor" onSubmit={(event) => void write(event)}>
        <label htmlFor={keyId}>Key</label>
        <input id={keyId} value={key} onChange={(event) => setKey(event.target.value)}
          placeholder="agent.max_turns" autoComplete="off" spellCheck={false} />
        <label htmlFor={valueId}>Value</label>
        <input id={valueId} value={value} onChange={(event) => setValue(event.target.value)}

        </div>
      </form>
      {formError && <p className="config-editor__error" role="alert">{formError}</p>}

export async function checkConfigEditor(browser, base, outDir) {
  const failures = [];
  const page = await browser.newPage({ viewport: { width: 1280, height: 1100 } });
  const errors = [];
  page.on("pageerror", (error) => errors.push(error.message));
  const valueOf = async (key) =>
    (await (await fetch(`${base}/api/lightagent/v1/config/${key}`)).json()).value;
  const set = page.getByRole("button", { name: "Set", exact: true });
  const valueField = page.getByLabel("Value", { exact: true });
  try {
    await page.goto(`${base}/#/settings`);
    await page.getByRole("heading", { name: "Advanced configuration" }).waitFor({ timeout: 15000 });

    await page.getByLabel("Key", { exact: true }).fill("memory.top_k");
    await page.getByRole("button", { name: "Read", exact: true }).click();
    await page.getByText("memory.top_k = ", { exact: false }).first().waitFor({ timeout: 5000 });

    await valueField.fill("7");
    await set.click();
    await page.getByText("Set memory.top_k = 7.", { exact: false }).waitFor({ timeout: 5000 });
    if (await valueOf("memory.top_k") !== "7") failures.push("config: the editor's write did not reach the config file");

    // Another writer changes the file; the editor still holds the older revision.
    const other = await fetch(`${base}/api/lightagent/v1/config/memory.top_k`, {
      method: "PUT",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ value: "8" }),
    });
    if (!other.ok) failures.push(`config: the direct write answered ${other.status}`);
    await valueField.fill("9");
    await set.click();
    await page.getByText("changed since it was loaded", { exact: false }).waitFor({ timeout: 5000 });
    if (await valueOf("memory.top_k") !== "8") failures.push("config: a stale write changed the config file");
    await page.screenshot({ path: `${outDir}/settings-config-stale.png` });

    // Reloaded, the same write now lands.
    await set.click();
    await page.getByText("Set memory.top_k = 9.", { exact: false }).waitFor({ timeout: 5000 });
    if (await valueOf("memory.top_k") !== "9") failures.push("config: the write after reloading did not land");

    // An invalid value is refused next to the form and writes nothing.
    await valueField.fill("lots");
    await set.click();
    await page.locator(".config-editor__error").waitFor({ timeout: 5000 });
    if (await valueOf("memory.top_k") !== "9") failures.push("config: an invalid value changed the config file");

    if (errors.length) failures.push(`config: uncaught page error — ${errors[0]}`);
    console.log(`  [${failures.length ? "FAIL" : "ok"}] settings advanced configuration`);
  } finally {
    await page.close();
  }
  return failures;
}

    let (tx, rx) = mpsc::channel();
    std::thread::spawn(move || {
        let mut line = String::new();
        let _ = BufReader::new(stdout).read_line(&mut line);
        let _ = tx.send(line);
    });
    let line = rx.recv_timeout(Duration::from_secs(60)).expect("handshake");
    let handshake: serde_json::Value = serde_json::from_str(&line).expect("handshake JSON");
    let addr = handshake["addr"].as_str().expect("addr").to_owned();
    Runtime {
        child,
        _lifeline: lifeline,
        addr,
    }
}

/// One authenticated request: the status, the raw body and its JSON.
fn call(
    runtime: &Runtime,
    method: &str,
    path: &str,
    body: Option<&str>,
) -> (u16, String, serde_json::Value) {
    let mut stream = TcpStream::connect(&runtime.addr).expect("connect");
    stream
        .set_read_timeout(Some(Duration::from_secs(10)))
        .expect("timeout");
    let body = body.unwrap_or("");
    let head = format!(
        "{method} {path} HTTP/1.1\r\nHost: {}\r\nAuthorization: Bearer {KEY}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        runtime.addr,
        body.len()
    );
    stream.write_all(head.as_bytes()).expect("send");
    let mut response = String::new();
    let _ = stream.read_to_string(&mut response);
    let status = response
        .split_whitespace()
        .nth(1)
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    let raw = response
        .split_once("\r\n\r\n")
        .map(|(_, body)| body.to_owned())
        .unwrap_or_default();
    let json = serde_json::from_str(&raw).unwrap_or(serde_json::Value::Null);
    (status, raw, json)
}

fn cli(home: &Path, args: &[&str]) -> Output {
    Command::new(env!("CARGO_BIN_EXE_lightagent"))
        .args(args)
        .env("LIGHTAGENT_HOME", home)
        .stdin(Stdio::null())
        .output()
        .expect("run lightagent")
}

/// What a successful CLI command printed.
fn cli_ok(home: &Path, args: &[&str]) -> String {
    let output = cli(home, args);
    assert!(
        output.status.success(),
        "{args:?}: {}",
        String::from_utf8_lossy(&output.stderr)
    );
    String::from_utf8_lossy(&output.stdout).trim().to_owned()
}

fn key_path(key: &str) -> String {
    format!("/api/lightagent/v1/config/{key}")
}

#[test]
fn api_config_reads_and_writes_are_the_cli_config_reads_and_writes() {
    let home = scratch_home("same");
    let runtime = start(&home);

    // A CLI write is what the API reads, and the other way round; neither
    // loses the other's change.
    cli_ok(&home, &["config", "set", "agent.max_turns", "7"]);
    let (status, _, read) = call(&runtime, "GET", &key_path("agent.max_turns"), None);
    assert_eq!((status, read["value"].as_str()), (200, Some("7")), "{read}");
    let body = serde_json::json!({ "value": "9" }).to_string();
    let (status, _, written) = call(&runtime, "PUT", &key_path("memory.top_k"), Some(&body));
    assert_eq!(status, 200, "{written}");
    assert_eq!(written["value"], "9");
    assert_eq!(cli_ok(&home, &["config", "get", "memory.top_k"]), "9");
    assert_eq!(cli_ok(&home, &["config", "get", "agent.max_turns"]), "7");

    // `config show` and GET /config show the same redacted configuration.
    let (status, _, shown) = call(&runtime, "GET", "/api/lightagent/v1/config", None);
    assert_eq!(status, 200, "{shown}");
    let cli_shown: serde_json::Value =
        serde_json::from_str(&cli_ok(&home, &["config", "show"])).expect("config show JSON");
    assert_eq!(shown["config"], cli_shown);
    assert_eq!(
        shown["path"].as_str().map(PathBuf::from),
        Some(PathBuf::from(cli_ok(&home, &["config", "path"])))
    );

    // The same invalid value and unknown key are refused with the same words.
    let output = cli(&home, &["config", "set", "memory.top_k", "lots"]);
    assert!(!output.status.success());
    let body = serde_json::json!({ "value": "lots" }).to_string();
    let (status, _, refused) = call(&runtime, "PUT", &key_path("memory.top_k"), Some(&body));
    assert_eq!(status, 400, "{refused}");
    let api_error = refused["error"].as_str().expect("error");
    assert!(
        String::from_utf8_lossy(&output.stderr).contains(api_error),
        "CLI: {} API: {api_error}",
        String::from_utf8_lossy(&output.stderr)
    );
    let output = cli(&home, &["config", "get", "no.such.key"]);
    assert!(!output.status.success());
    let (status, _, missing) = call(&runtime, "GET", &key_path("no.such.key"), None);
    assert_eq!(status, 404, "{missing}");
    assert!(
        String::from_utf8_lossy(&output.stderr)
            .contains(missing["error"].as_str().expect("error")),
        "{missing}"
    );
    assert_eq!(cli_ok(&home, &["config", "get", "memory.top_k"]), "9");
}

#[test]
fn a_stale_write_is_refused_with_409_and_writes_nothing() {
    let home = scratch_home("stale");
    let runtime = start(&home);
    let (_, _, first) = call(&runtime, "GET", "/api/lightagent/v1/config", None);
    let read_at = first["revision"].as_str().expect("revision").to_owned();

    // Another writer, after the revision was read.
    cli_ok(&home, &["config", "set", "agent.max_turns", "11"]);
    let config_file = home.join("config.json");
    let before = std::fs::read(&config_file).expect("config");
    let body = serde_json::json!({ "value": "3", "expected_revision": read_at }).to_string();
    let (status, _, refused) = call(&runtime, "PUT", &key_path("memory.top_k"), Some(&body));
    assert_eq!(status, 409, "{refused}");
    let (_, _, now) = call(&runtime, "GET", "/api/lightagent/v1/config", None);
    assert_eq!(refused["revision"], now["revision"]);
    assert_eq!(std::fs::read(&config_file).expect("config"), before);

    // With the current revision it lands, and the other writer's change stays.
    let body = serde_json::json!({ "value": "3", "expected_revision": now["revision"] }).to_string();
    let (status, _, written) = call(&runtime, "PUT", &key_path("memory.top_k"), Some(&body));
    assert_eq!(status, 200, "{written}");
    assert_eq!(cli_ok(&home, &["config", "get", "agent.max_turns"]), "11");
    assert_eq!(cli_ok(&home, &["config", "get", "memory.top_k"]), "3");

    // The Settings screen's save is checked the same way.
    let (status, _, settings) = call(&runtime, "GET", "/api/lightagent/v1/settings", None);
    assert_eq!(status, 200, "{settings}");
    cli_ok(&home, &["config", "set", "memory.top_k", "4"]);
    let mut stale = settings.clone();
    stale["expected_revision"] = settings["revision"].clone();
    stale["max_turns"] = 5.into();
    let (status, _, refused) = call(
        &runtime,
        "PUT",
        "/api/lightagent/v1/settings",
        Some(&stale.to_string()),
    );
    assert_eq!(status, 409, "{refused}");
    assert_eq!(cli_ok(&home, &["config", "get", "agent.max_turns"]), "11");

    // Without a revision, the save applies to the config as it is now and
    // keeps the CLI's change made since the screen was loaded.
    let mut fresh = settings.clone();
    fresh["max_turns"] = 5.into();
    let (status, _, saved) = call(
        &runtime,
        "PUT",
        "/api/lightagent/v1/settings",
        Some(&fresh.to_string()),
    );
    assert_eq!(status, 200, "{saved}");
    assert_eq!(cli_ok(&home, &["config", "get", "agent.max_turns"]), "5");
    assert_eq!(cli_ok(&home, &["config", "get", "memory.top_k"]), "4");
}

#[test]
fn a_secret_saved_through_settings_never_appears_in_cli_or_api_output() {
    let home = scratch_home("secret");
    let runtime = start(&home);
    let (_, _, mut settings) = call(&runtime, "GET", "/api/lightagent/v1/settings", None);
    settings["jev"]["api_key"] = SECRET.into();
    let (status, raw, _) = call(
        &runtime,
        "PUT",
        "/api/lightagent/v1/settings",
        Some(&settings.to_string()),
    );
    assert_eq!(status, 200, "{raw}");
    assert!(!raw.contains(SECRET));

    let (_, raw, shown) = call(&runtime, "GET", "/api/lightagent/v1/config", None);
    assert!(!raw.contains(SECRET), "GET /config: {raw}");
    // The secret was stored: the config refers to it.
    assert!(
        !shown["config"]["platform"]["jev"]["api_key"].is_null(),
        "{shown}"
    );
    for path in [
        "/api/lightagent/v1/settings".to_owned(),
        key_path("inference.api_key"),
    ] {
        let (_, raw, _) = call(&runtime, "GET", &path, None);
        assert!(!raw.contains(SECRET), "{path}: {raw}");
    }
    for args in [
        vec!["config", "show"],
        vec!["config", "get", "inference.api_key"],
    ] {
        let output = cli(&home, &args);
        assert!(
            !String::from_utf8_lossy(&output.stdout).contains(SECRET)
                && !String::from_utf8_lossy(&output.stderr).contains(SECRET),
            "{args:?}"
        );
    }
}

#[test]
fn one_lock_holds_every_process_and_a_waiting_writer_keeps_the_holders_change() {
    let home = scratch_home("lock");
    cli_ok(&home, &["config", "set", "agent.max_turns", "7"]);
    let lock = OpenOptions::new()
        .create(true)
        .truncate(false)
        .write(true)
        .open(home.join("config.json.lock"))
        .expect("lock file");
    lock.lock().expect("hold the config lock");
    let writer = Command::new(env!("CARGO_BIN_EXE_lightagent"))
        .args(["config", "set", "agent.max_tool_calls", "11"])
        .env("LIGHTAGENT_HOME", &home)
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .expect("start the CLI writer");
    let mut writer = writer;
    std::thread::sleep(Duration::from_millis(800));
    assert!(
        writer.try_wait().expect("poll").is_none(),
        "the CLI wrote while another process held the config lock"
    );
    // Another writer, inside the lock: a change the waiting CLI must keep.
    let path = home.join("config.json");
    let mut value: serde_json::Value =
        serde_json::from_slice(&std::fs::read(&path).expect("read")).expect("config JSON");
    value["memory"]["top_k"] = 9.into();
    std::fs::write(&path, serde_json::to_vec_pretty(&value).expect("JSON")).expect("write");
    lock.unlock().expect("release");
    let output = writer.wait_with_output().expect("wait");
    assert!(
        output.status.success(),
        "{}",
        String::from_utf8_lossy(&output.stderr)
    );
    for (key, expected) in [
        ("agent.max_turns", "7"),
        ("agent.max_tool_calls", "11"),
        ("memory.top_k", "9"),
    ] {
        assert_eq!(cli_ok(&home, &["config", "get", key]), expected, "{key}");
    }
}

## D4c — Configuration: one locked, revision-checked writer

Prerequisite: D4b head `7c3e988` (tree `494dffb`) passed `check`
https://github.com/dlroqa/Lightagent/actions/runs/41357376468 and `desktop`

- **One writer.** `ConfigStore::update(expected, change)` in
  `lightagent-core`:
  1. Takes an exclusive OS lock on `config.json.lock` (std
     `File::try_lock`, so every process takes it, with no new dependency).
  2. Reads the file as it is now.
  3. Refuses an `expected` revision that no longer matches as `Conflict`. A
     revision is `sha256:` plus the hash of the file's bytes, or `absent`.
  4. Applies the change, validates the result, and writes atomically.

  A lock held longer than 5 s reports `Busy`, so a writer never waits
  indefinitely. `replace(expected, config)` is the revision-checked form for
  an editor working on a copy. `save` keeps its signature but takes the lock.
- **Every writer converted:**
  - `lightagent config set` and `init`;
  - extension install, enable and disable;
  - chat Markdown onboarding;
  - `setup`, which is revision-checked: it refuses to save over a change
    made while it was open, and says so;
  - `PUT /settings`, now a locked read-modify-write. With
    `expected_revision`, a stale save gets 409.
- **CLI = API.** The key rules of `config get|set` moved to
  `lightagent_core::config_keys`. New routes:
  - `GET /config`: the path, the revision, and the redacted config;
  - `GET /config/{key}`;
  - `PUT /config/{key}`, which takes `expected_revision` and gives 409 when
    it is stale.

  All three require the admin scope, like `/settings`. An invalid value gets
  400 with the CLI's exact message, a busy lock gets 503, and a conflict
