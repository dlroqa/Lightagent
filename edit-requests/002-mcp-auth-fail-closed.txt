=== message
Keep an MCP server unreached when its configured auth cannot be used

An HTTP MCP server's installation `auth` that resolved to nothing (an
unset variable, an unreadable or empty file) used to connect without a
bearer while still sending the custom headers. When that `auth` is used
for the run (an operator run, or a profile granted the server's
credentials) and cannot be, the server is now not contacted at all, and
the run reports `mcp_auth_unusable` with a fixed category:
credential_unresolved, credential_unreadable, credential_empty or
credential_invalid_header. A value is invalid when the HTTP client could
not send it in an Authorization header. Reports carry the server's name
and the category only, never the value, the path or variable, or an
error's text.

Servers without `auth`, runs not granted the credentials, profile grants
and other servers are unchanged. `SecretRef::lookup` is new and
additive; `SecretRef::resolve` is unchanged for every other caller.

/// Why a configured MCP `auth` cannot be used. Each is a fixed category, safe
/// to show: none carries the value, the reference's path or variable, or an
/// underlying error's text, any of which could hold a secret.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub(crate) enum CredentialProblem {
    /// The environment variable is unset (or not Unicode).
    Unresolved,
    /// The file could not be read.
    Unreadable,
    /// The value is empty or only whitespace.
    Empty,
    /// The value cannot be sent in an `Authorization` header.
    InvalidHeader,
}

impl CredentialProblem {
    /// The category's fixed code.
    pub(crate) fn code(self) -> &'static str {
        match self {
            Self::Unresolved => "credential_unresolved",
            Self::Unreadable => "credential_unreadable",
            Self::Empty => "credential_empty",
            Self::InvalidHeader => "credential_invalid_header",
        }
    }
}

/// An HTTP MCP server whose configured `auth` cannot be used for this run. It
/// is not contacted at all: no bearer, none of its custom headers, and never
/// an unauthenticated request in their place.
#[derive(Clone, Debug, PartialEq, Eq)]
pub(crate) struct McpAuthRefusal {
    pub(crate) server: String,
    pub(crate) problem: CredentialProblem,
}

impl std::fmt::Display for McpAuthRefusal {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(
            f,
            "mcp_auth_unusable ({}): its configured auth cannot be used, so it was not contacted",
            self.problem.code()
        )
    }
}

/// The servers to connect for a run, and those refused because their
/// configured `auth` cannot be used. A server the run may not use is in
/// neither.
fn plan_mcp_servers(
    config: &Config,
    extensions: &ExtensionStore,
    access: RemoteAccess<'_>,
) -> (Vec<McpServerSpec>, Vec<McpAuthRefusal>) {
    let configured = config
        .mcp
        .servers
        .iter()
        .map(|entry| (entry, None::<&Path>));
    let installed = extensions.active(&config.extensions).flat_map(|ext| {
        ext.mcp_servers
            .iter()
            .map(move |entry| (entry, Some(ext.dir.as_path())))
    });
    let mut specs = Vec::new();
    let mut refused = Vec::new();
    for (entry, cwd) in configured.chain(installed) {
        match to_mcp_spec(entry, cwd, access) {
            Ok(Some(spec)) => specs.push(spec),
            Ok(None) => {}
            Err(refusal) => refused.push(refusal),
        }
    }
    (specs, refused)
}

/// The bearer a configured `auth` gives, or why it cannot be used. The value
/// must make the `Authorization` header the HTTP client would send, so one it
/// would refuse fails here, before any request.
fn usable_bearer(secret: &lightagent_core::SecretRef) -> Result<String, CredentialProblem> {
    use lightagent_core::SecretLookup;
    match secret.lookup() {
        SecretLookup::Value(value) => {
            match reqwest::header::HeaderValue::from_bytes(format!("Bearer {value}").as_bytes()) {
                Ok(_) => Ok(value),
                Err(_) => Err(CredentialProblem::InvalidHeader),
            }
        }
        SecretLookup::Unresolved => Err(CredentialProblem::Unresolved),
        SecretLookup::Unreadable => Err(CredentialProblem::Unreadable),
        SecretLookup::Empty => Err(CredentialProblem::Empty),
    }
}
