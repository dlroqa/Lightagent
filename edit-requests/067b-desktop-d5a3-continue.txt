=== message
D5a-3: a run paused on its time budget continues over the API; steering

Time budget, as it was: an API run wraps up (one final tool-less turn,
then WallClockExceeded) and keeps nothing to resume. Only the terminal
paused, holding the loop's suspended state (the conversation with the tool
results the model has not read, and the turn and tool-call counts) in
memory, and `/continue` resumed that same execution. A new turn on the
session is not that: it starts a new execution from the saved transcript,
which does not hold unread tool results.

Now an API run may ask for the terminal's behavior:
- `POST /runs` takes `on_time_budget: "pause"` (default `wrap_up`, as
  before). Such a run pauses when its budget runs out with unread tool
  results: event `run.paused` {reason, elapsed_secs}, status
  `awaiting_continue`. It keeps its session lease and journal meanwhile.
- `POST /runs/{id}/continue` {mode: `extend` | `answer`} resumes the same
  execution: `extend` renews only the clock (turn and tool-call budgets
  still count) and carries on with tools; `answer` takes the final
  tool-less turn. 409 unless the run is paused. A revoked run takes none.
  A cancel ends a paused run (`run.cancelled`).
- The desktop contract gains `runs.continue`, refused during a profile
  switch like `runs.create`. The inventory gains its API row (not counted;
  it serves `slash.continue`, still not started until its UI is verified).
- The run factory trait gains `run_controlled` with a default that runs as
  before, so factories that cannot pause never do.

Steering: kept as it is, a FIFO queue held by the client (the terminal
process, the Web UI page) that sends each queued instruction as the
session's next turn once the session is free. Nothing is applied inside a
running turn; the queue does not survive its client; duplicate or
concurrent submissions are settled by the server's one-turn-per-session
admission. No backend queue is added (inventory `key.steer` updated).

OS locks: every `paths::lock_exclusive` lock (config, session writes, run
leases) is now an `ExclusiveLock` that unlocks before it closes, so none
stays held while a child is between fork and exec (row 20 fixed only the
run lease).

Evidence:
- crates/lightagent/tests/desktop_continue.rs (separate processes, all
  platforms): a paused run is `awaiting_continue` with one provider
  request; `extend` sends the next turn with the unread tool result and
  the tools; a second continue is refused; cancel while paused releases
  the session; a run that did not ask to pause wraps up.
- crates/lightagent/tests/desktop_interrupted.rs: a second runtime
  started while the first is mid-turn does not mark that turn
  Interrupted; it records it only after the first process is gone.
- run_lease.rs: a write lock dropped while a child is starting is free at
  once.
- desktop/e2e/runs.py `continue` (extend, answer, cancel, default
  wrap-up) and `steering` (busy refusal, two concurrent submissions with
  exactly one admitted, queued turns run in order) through the host.

/// An exclusive OS lock on a file, from [`lock_exclusive`]. Dropping it
/// unlocks, then closes. The lock belongs to the open file, which a child
/// that another thread is starting shares until its exec closes its copy, so
/// closing only this handle would keep the lock held until then; unlocking
/// releases it at once, whoever else still has the file open.
#[derive(Debug)]
pub struct ExclusiveLock {
    file: Option<std::fs::File>,
}

impl ExclusiveLock {
    /// The open file, still locked, without the unlock on drop: the lock then
    /// lasts until every copy of the file is closed (tests use this as a
    /// control).
    pub fn into_file(mut self) -> std::fs::File {
        self.file
            .take()
            .expect("a lock holds its file until it is dropped")
    }
}

impl Drop for ExclusiveLock {
    fn drop(&mut self) {
        if let Some(file) = &self.file {
            let _ = file.unlock();
        }
    }
}

/// One authenticated request: the status and the raw body.
fn call(runtime: &Runtime, method: &str, path: &str, body: Option<&str>) -> (u16, String) {
    let mut stream = TcpStream::connect(&runtime.addr).expect("connect");
    stream
        .set_read_timeout(Some(Duration::from_secs(60)))
        .expect("timeout");
    let body = body.unwrap_or("");
    let head = format!(
        "{method} {path} HTTP/1.1\r\nHost: {}\r\nAuthorization: Bearer {KEY}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        runtime.addr,
        body.len()
    );
    stream.write_all(head.as_bytes()).expect("send");
    let mut response = String::new();
    let _ = stream.read_to_string(&mut response);
    let status = response
        .split_whitespace()
        .nth(1)
        .and_then(|code| code.parse().ok())
        .unwrap_or(0);
    let raw = response
        .split_once("\r\n\r\n")
        .map(|(_, body)| body.to_owned())
        .unwrap_or_default();
    (status, raw)
}

/// Read one request; return its head and body.
fn read_request(stream: &mut TcpStream) -> Option<(String, String)> {
    let _ = stream.set_read_timeout(Some(Duration::from_secs(10)));
    let mut bytes = Vec::new();
    let mut buffer = [0u8; 4096];
    loop {
        if let Some(end) = bytes.windows(4).position(|window| window == b"\r\n\r\n") {
            let head = String::from_utf8_lossy(&bytes[..end]).into_owned();
            let length = head
                .lines()
                .find_map(|line| {
                    line.to_ascii_lowercase()
                        .strip_prefix("content-length:")
                        .map(|value| value.trim().parse::<usize>().unwrap_or(0))
                })
                .unwrap_or(0);
            if bytes.len() >= end + 4 + length {
                let body = String::from_utf8_lossy(&bytes[end + 4..end + 4 + length]).into_owned();
                return Some((head, body));
            }
        }
        match stream.read(&mut buffer) {
            Ok(0) | Err(_) => return None,
            Ok(read) => bytes.extend_from_slice(&buffer[..read]),
        }
    }
}

fn sse(chunks: &[Value]) -> String {
    let mut response =
        "HTTP/1.1 200 OK\r\ncontent-type: text/event-stream\r\nconnection: close\r\n\r\n".to_owned();
    for chunk in chunks {
        response.push_str(&format!("data: {chunk}\n\n"));
    }
    response.push_str("data: [DONE]\n\n");
    response
}

/// A provider that, when the conversation ends with the user's prompt,
/// asks for `datetime.now` and takes longer than the run's one-second time
/// budget; when it ends with a tool result, it answers "Found it.". Every
/// request body is kept.
fn provider() -> (String, Arc<Mutex<Vec<Value>>>) {
    let listener = TcpListener::bind("127.0.0.1:0").expect("listener");
    let url = format!("http://{}", listener.local_addr().expect("address"));
    let bodies = Arc::new(Mutex::new(Vec::new()));
    let kept = Arc::clone(&bodies);
    std::thread::spawn(move || {
        for stream in listener.incoming() {
            let Ok(mut stream) = stream else { continue };
            let kept = Arc::clone(&kept);
            std::thread::spawn(move || {
                let Some((head, body)) = read_request(&mut stream) else {
                    return;
                };
                if head.starts_with("GET") {
                    let response = format!(
                        "HTTP/1.1 200 OK\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{MODELS}",
                        MODELS.len()
                    );
                    let _ = stream.write_all(response.as_bytes());
                    return;
                }
                let request: Value = serde_json::from_str(&body).unwrap_or(Value::Null);
                kept.lock().expect("bodies").push(request.clone());
                let last_role = request["messages"]
                    .as_array()
                    .and_then(|messages| messages.last())
                    .map(|message| message["role"].as_str().unwrap_or("").to_owned())
                    .unwrap_or_default();
                if last_role == "tool" {
                    let answer = sse(&[
                        json!({"choices":[{"index":0,"delta":{"role":"assistant","content":"Found it."}}]}),
                        json!({"choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}),
                    ]);
                    let _ = stream.write_all(answer.as_bytes());
                    return;
                }
                let tool = request["tools"]
                    .as_array()
                    .into_iter()
                    .flatten()
                    .filter_map(|tool| tool["function"]["name"].as_str())
                    .find(|name| {
                        name.chars()
                            .filter(char::is_ascii_alphanumeric)
                            .collect::<String>()
                            .eq_ignore_ascii_case("datetimenow")
                    })
                    .unwrap_or("datetime.now")
                    .to_owned();
                std::thread::sleep(Duration::from_millis(1500));
                let call = sse(&[
                    json!({"choices":[{"index":0,"delta":{"role":"assistant","tool_calls":[{"index":0,"id":"call_1","type":"function","function":{"name":tool,"arguments":"{}"}}]}}]}),
                    json!({"choices":[{"index":0,"delta":{},"finish_reason":"tool_calls"}]}),
                ]);
                let _ = stream.write_all(call.as_bytes());
            });
        }
    });
    (url, bodies)
}

def scripts(provider):
    def write(name, content):
        return ("tool", "fs.write", {"path": name, "content": content, "append": True})

    def slow_lookup(p, turn, index):
        # The tool's turn outlasts a one-second budget, so the budget runs
        # out with its result unread.
        if turn == 0:
            return [("tool", "datetime.now", {}), ("sleep", 1.5), ("finish", "tool_calls")]
        return [("text", "Found it."), ("finish", "stop")]

    for name in ("continue-extend", "continue-answer", "continue-cancel", "continue-default"):
        provider.scripts[name] = slow_lookup

def scenario_continue(host, provider, workspace):
    check = Checks("continue")
    status, body = host.fetch("PUT", f"{API}/config/agent.wall_clock_secs", {"value": "1"})
    check.expect("a one-second time budget is set through the host", status == 200, (status, body))
    try:
        for mode in ("extend", "answer"):
            name = f"continue-{mode}"
            session = host.new_session()
            status, created = host.fetch(
                "POST", f"{API}/runs",
                {"message": f"[e2e:{name}] Look it up.", "session_id": session, "on_time_budget": "pause"},
            )
            check.expect(f"{mode}: the run starts", status == 202, (status, created))
            if status != 202:
                continue
            run = created["id"]
            stream = Stream(host, run)
            paused = stream.until(lambda s: s.has("run.paused"))
            _, info = host.fetch("GET", f"{API}/runs/{run}")
            waiting = len(provider.requests(name))
            status, answered = host.fetch("POST", f"{API}/runs/{run}/continue", {"mode": mode})
            stream.finish()
            again = host.fetch("POST", f"{API}/runs/{run}/continue", {"mode": mode})
            requests = provider.requests(name)
            final = (stream.data("run.completed") or [{}])[-1]
            check.expect(f"{mode}: the run paused on its budget", paused and (info or {}).get("status") == "awaiting_continue", (stream.names(), info))
            check.expect(f"{mode}: nothing was sent while paused", waiting == 1, waiting)
            check.expect(f"{mode}: the continue was taken", status == 200 and (answered or {}).get("continued") is True, (status, answered))
            check.expect(f"{mode}: the same execution carried on", len(requests) == 2 and requests[1]["roles"][-1:] == ["tool"], requests)
            if mode == "extend":
                check.expect("extend: the tools are offered again", len(requests) == 2 and requests[1]["offered"] > 0, requests)
                check.expect("extend: the run completed", final.get("reason") == "EndTurn", final)
            else:
                check.expect("answer: the final turn has no tools", len(requests) == 2 and requests[1]["offered"] == 0, requests)
                check.expect("answer: it ended on the budget", final.get("reason") == "WallClockExceeded", final)
            check.expect(f"{mode}: the answer arrived", "Found it." in stream.text(), stream.text())
            check.expect(f"{mode}: a second continue is refused", again[0] == 409, again)

        session = host.new_session()
        status, created = host.fetch(
            "POST", f"{API}/runs",
            {"message": "[e2e:continue-cancel] Look it up.", "session_id": session, "on_time_budget": "pause"},
        )
        if status == 202:
            run = created["id"]
            stream = Stream(host, run)
            stream.until(lambda s: s.has("run.paused"))
            host.fetch("POST", f"{API}/runs/{run}/cancel", {})
            stream.finish()
            _, info = host.fetch("GET", f"{API}/runs/{run}")
            check.expect("cancel: a paused run is cancelled", (info or {}).get("status") == "cancelled" and stream.has("run.cancelled"), (info, stream.names()))
            check.expect("cancel: nothing more was sent", len(provider.requests("continue-cancel")) == 1, provider.requests("continue-cancel"))
        else:
            check.expect("cancel: the run starts", False, (status, created))

        session = host.new_session()
        stream = Stream(host, host.start_run(session, "[e2e:continue-default] Look it up.")).finish()
        requests = provider.requests("continue-default")
        final = (stream.data("run.completed") or [{}])[-1]
        check.expect("default: a run that did not ask never pauses", not stream.has("run.paused"), stream.names())
        check.expect("default: it wraps up without tools", final.get("reason") == "WallClockExceeded" and len(requests) == 2 and requests[1]["offered"] == 0, (final, requests))
    finally:
        host.fetch("PUT", f"{API}/config/agent.wall_clock_secs", {"value": ""})
    return check


def scenario_steering(host, provider, workspace):
    check = Checks("steering")
    session = host.new_session()
    first = host.start_run(session, "[e2e:steer-hold] Start.")
    stream = Stream(host, first)
    stream.until(lambda s: "Working" in s.text())
    busy = host.fetch("POST", f"{API}/runs", {"message": "[e2e:steer] Too early.", "session_id": session})
    provider.open("steer-hold")
    stream.finish()
    recorded(host, session, 1)
    check.expect("a steer sent while the session is busy is refused", busy[0] == 409, busy)

    # Two clients send their queued steer at once: exactly one is admitted.
    deadline = time.time() + 10
    while True:
        sent = [
            host.send("fetch", method="POST", target=f"{API}/runs",
                      body=json.dumps({"message": f"[e2e:steer] Steer {n}.", "session_id": session}))
            for n in (1, 2)
        ]
        answers = [host.answer(ident) for ident in sent]
        statuses = sorted(answer["status"] for answer in answers)
        if statuses != [409, 409] or time.time() > deadline:
            break
        time.sleep(0.1)
    check.expect("two clients at once: exactly one is admitted", statuses == [202, 409], statuses)
    if statuses == [202, 409]:
        won = 0 if answers[0]["status"] == 202 else 1
        Stream(host, json.loads(answers[won]["body"])["id"]).finish()
        recorded(host, session, 2)
        other = f"[e2e:steer] Steer {2 - won}."
        deadline, follow = time.time() + 10, None
        while time.time() < deadline:
            follow = host.fetch("POST", f"{API}/runs", {"message": other, "session_id": session})
            if follow[0] != 409:
                break
            time.sleep(0.1)
        if follow and follow[0] == 202:
            Stream(host, follow[1]["id"]).finish()
        saved = recorded(host, session, 3)
        prompts = [m.get("content") for m in saved.get("messages", []) if m.get("role") == "user"]
        expected = ["[e2e:steer-hold] Start.", f"[e2e:steer] Steer {won + 1}.", other]
        check.expect("the queued turns ran in the order admitted, the refused one never saved", prompts == expected, prompts)
    return check
