=== message
Broker: count queue time only when the run was seen queued

The live check on e0e3ab4 (run 41616581374) showed a run that had
already completed at the first read reported as queued for 162 ms: the
time spent reading its jobs. The wait diagnostics now count queue time
only when a read saw the run requested, queued, pending or waiting. A
deterministic test covers a run that has completed before the first read
(passed, nothing queued or running).

Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>

#[tokio::test]
async fn a_run_completed_before_the_first_read_was_never_seen_queued() {
    let github = github().await;
    staged(&github, 508, &[("completed", Some("success"))]);
    let ctx = waiting(&github, Duration::from_secs(5), Duration::from_secs(5));
    let status = wait_for(&ctx, 508, 30).await;
    assert_eq!(status["verdict"], "passed", "{status}");
    assert_eq!(status["wait"]["outcome"], "completed", "{status}");
    assert_eq!(status["wait"]["queued_ms"], 0, "{status}");
    assert_eq!(status["wait"]["running_ms"], 0, "{status}");
}
