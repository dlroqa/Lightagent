Row 53: the audit's evidence gaps (test-only)

The rows 41-52 evidence audit found five rows with a UI path and backend
tests but no complete check at one level. This adds those checks; no
product code changes.

- identity credential rotate --expires-in: the browser rotates with an
  expiry and the replacement expires in about that time.
- remote-credential list --profile: the browser's Show filter asks the API
  for one profile, and a profile with no grants shows none.
- init --profile and --base-url: the browser asserts what Reconfigure sent
  (force, profile, base URL, model).
- LIGHTAGENT_HOME: the home doctor reports is the variable's home in the
  backend test, through the host (which passes its environment to the
  runtime), and on the Diagnostics screen.
