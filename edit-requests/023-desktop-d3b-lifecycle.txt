=== message
Desktop D3b: crash detection, bounded restart, single instance

The host watches its runtime: an unexpected exit is reported with its
status and output and restarted at most once a minute. Users can restart
it and read its log from the start-up gate, which now keeps watching and
shows a notice over the kept app. A second launch takes no runtime of its
own (an exclusive lock on instance.lock) and says so. The shell CI adds
crash and duplicate end-to-end modes and runs Linux with a session bus.

import { useCallback, useEffect, useRef, useState, type ReactNode, type RefObject } from "react";

import { invoke, isDesktop } from "../api/transport";
import "./desktop-gate.css";

/** The desktop host's view of its bundled runtime (`runtime_status`). */
interface RuntimeStatus {
  state: "starting" | "ready" | "failed" | "mismatch" | "duplicate";
  detail: string | null;
  desktop_version: string;
  runtime_version: string | null;
  profile: string | null;
}

/** How often the gate re-checks the runtime once the app is running. */
const WATCH_MS = 2000;

/**
 * In the desktop app: hold the UI until the bundled runtime is ready, keep
 * watching it afterwards, and explain plainly — with a way out — when it
 * cannot start, stops, does not match, or another window already owns it.
 * In the browser build this renders its children directly.
 */
export function DesktopGate({ children }: { children: ReactNode }) {
  const [status, setStatus] = useState<RuntimeStatus | null>(null);
  const [hostError, setHostError] = useState<string | null>(null);
  const [everReady, setEverReady] = useState(false);
  const [restarting, setRestarting] = useState(false);
  const [logs, setLogs] = useState<string[] | null>(null);
  const [generation, setGeneration] = useState(0);
  const heading = useRef<HTMLHeadingElement>(null);

  useEffect(() => {
    if (!isDesktop) return;
    let stopped = false;
    let timer: number | undefined;
    const poll = async () => {
      try {
        const next = await invoke<RuntimeStatus>("runtime_status");
        if (stopped) return;
        setStatus(next);
        setHostError(null);
        if (next.state === "ready") {
          setEverReady(true);
          setRestarting(false);
          void invoke("e2e_note", { note: "ui_ready" }).catch(() => undefined);
        } else if (next.state !== "starting") {
          setRestarting(false);
          void invoke("e2e_note", { note: "ui_error" }).catch(() => undefined);
        }
        timer = window.setTimeout(() => void poll(), next.state === "starting" ? 250 : WATCH_MS);
      } catch (cause) {
        if (!stopped) setHostError(cause instanceof Error ? cause.message : String(cause));
      }
    };
    void poll();
    return () => {
      stopped = true;
      if (timer !== undefined) window.clearTimeout(timer);
    };
  }, [generation]);

  const failed =
    hostError !== null ||
    status?.state === "failed" ||
    status?.state === "mismatch" ||
    status?.state === "duplicate";

  useEffect(() => {
    if (failed) heading.current?.focus();
  }, [failed]);

  const restart = useCallback(async () => {
    setRestarting(true);
    setLogs(null);
    try {
      await invoke("runtime_restart");
    } catch (cause) {
      setHostError(cause instanceof Error ? cause.message : String(cause));
      setRestarting(false);
    }
    setGeneration((value) => value + 1);
  }, []);

  const showLogs = useCallback(async () => {
    try {
      setLogs(await invoke<string[]>("runtime_logs", { limit: 200 }));
    } catch {
      setLogs([]);
    }
  }, []);

  if (!isDesktop) return <>{children}</>;
  const ready = status?.state === "ready" && hostError === null;
  if (ready) return <>{children}</>;

  const panel = failed && !restarting ? (
    <FailurePanel
      status={status}
      hostError={hostError}
      heading={heading}
      logs={logs}
      onRestart={() => void restart()}
      onShowLogs={() => void showLogs()}
    />
  ) : (
    <div className="desktop-gate__panel" role="status" aria-live="polite">
      <span className="desktop-gate__pulse" aria-hidden="true" />
      <h1 className="desktop-gate__title">
        {everReady || restarting ? "Restarting Lightagent's runtime…" : "Starting Lightagent…"}
      </h1>
      <p className="desktop-gate__text">Starting the bundled runtime on this computer.</p>
    </div>
  );

  // After the app has been running, keep it mounted under the notice so
  // nothing on screen is lost while the runtime recovers.
  if (everReady) {
    return (
      <>
        <div aria-hidden="true" inert>
          {children}
        </div>
        <div className="desktop-gate desktop-gate--overlay" role="presentation">
          {panel}
        </div>
      </>
    );
  }
  return <main className="desktop-gate">{panel}</main>;
}

function FailurePanel(props: {
  status: RuntimeStatus | null;
  hostError: string | null;
  heading: RefObject<HTMLHeadingElement | null>;
  logs: string[] | null;
  onRestart: () => void;
  onShowLogs: () => void;
}) {
  const { status, hostError, heading, logs } = props;
  const state = status?.state;
  const title =
    state === "mismatch"
      ? "The bundled runtime does not match this app"
      : state === "duplicate"
        ? "Lightagent is already open"
        : "Lightagent's runtime is not running";
  const remedy =
    state === "mismatch"
      ? "Reinstall Lightagent Desktop so the app and its runtime come from the same release. Nothing was run."
      : state === "duplicate"
        ? "Switch to the window that is already open. Close this one; it has not started anything."
        : "Restart the runtime. If it stops again, the runtime log shows why.";
  return (
    <div className="desktop-gate__panel desktop-gate__panel--error" role="alert">
      <h1 className="desktop-gate__title" tabIndex={-1} ref={heading}>
        {title}
      </h1>
      <p className="desktop-gate__text">{hostError ?? status?.detail ?? "The runtime stopped before it was ready."}</p>
      <p className="desktop-gate__text desktop-gate__text--muted">{remedy}</p>
      <dl className="desktop-gate__facts">
        <dt>App</dt>
        <dd>{status?.desktop_version ?? "unknown"}</dd>
        <dt>Runtime</dt>
        <dd>{status?.runtime_version ?? "not reported"}</dd>
      </dl>
      {state !== "duplicate" && (
        <div className="desktop-gate__actions">
          <button type="button" className="btn btn--primary" onClick={props.onRestart}>
            Restart runtime
          </button>
          <button type="button" className="btn" onClick={props.onShowLogs} aria-expanded={logs !== null}>
            Runtime log
          </button>
        </div>
      )}
      {logs !== null && (
        <pre className="desktop-gate__log" tabIndex={0} aria-label="Runtime log, most recent lines last">
          {logs.length ? logs.join("\n") : "The runtime wrote nothing before it stopped."}
        </pre>
      )}
    </div>
  );
}

use serde::Serialize;
use tauri::Manager as _;
use tokio::sync::Notify;

const VERSION: &str = env!("CARGO_PKG_VERSION");
/// The longest a single events poll waits for something to arrive.
const MAX_POLL: Duration = Duration::from_secs(25);
/// At most one automatic restart of a crashed runtime in this window; a
/// runtime that keeps failing stays down and says so.
const AUTO_RESTART_WINDOW: Duration = Duration::from_secs(60);
/// How often the host checks that its runtime is still alive.
const WATCH_INTERVAL: Duration = Duration::from_millis(500);

enum Runtime {
    Starting,
    Ready(sidecar::Sidecar),
    Failed(String),
    Mismatch { expected: String, found: String },
    /// Another Lightagent Desktop already owns this app's data; this window
    /// starts no runtime of its own.
    Duplicate,
}

struct Host {
    contract: contract::Contract,
    runtime: Mutex<Runtime>,
    http: reqwest::Client,
    subscriptions: Mutex<HashMap<u64, Arc<Subscription>>>,
    next_subscription: AtomicU64,
    e2e: E2e,
    /// When the runtime was last restarted automatically.
    last_auto_restart: Mutex<Option<Instant>>,
    /// The output of the last runtime that stopped, kept for diagnostics.
    last_logs: Mutex<Vec<String>>,
    /// The single-instance lock, held for the app's lifetime.
    instance: Mutex<Option<std::fs::File>>,
}

#[derive(Default)]
struct Subscription {
    state: Mutex<SubscriptionState>,
    notify: Notify,
    task: Mutex<Option<tauri::async_runtime::JoinHandle<()>>>,
}

#[derive(Default)]
struct SubscriptionState {
    events: VecDeque<sse::SseEvent>,
    closed: bool,
    error: Option<String>,
}

fn lock<T>(mutex: &Mutex<T>) -> MutexGuard<'_, T> {
    mutex.lock().unwrap_or_else(PoisonError::into_inner)
}

impl Host {
    /// The runtime's base URL and authorization, copied out so no lock is held
    /// across a request.
    fn connection(&self) -> Result<(String, String), String> {
        match &*lock(&self.runtime) {
            Runtime::Ready(sidecar) => Ok((sidecar.base_url(), sidecar.authorization())),
            Runtime::Starting => Err("the runtime is still starting".to_owned()),
            Runtime::Failed(reason) => Err(format!("the runtime is unavailable: {reason}")),
            Runtime::Mismatch { .. } => {
                Err("the runtime version does not match this app".to_owned())
            }
            Runtime::Duplicate => Err("another Lightagent window owns this data".to_owned()),
        }
    }

    fn stop_runtime(&self) {
        let previous = std::mem::replace(
            &mut *lock(&self.runtime),
            Runtime::Failed("stopped".to_owned()),
        );
        drop(previous);
    }
}

/// Unattended-test evidence: when `LIGHTAGENT_DESKTOP_E2E_REPORT` names a
/// file, milestones are appended to it. Nothing secret is ever written.
struct E2e {
    path: Option<PathBuf>,
    started: Instant,
    seen: Mutex<HashSet<String>>,
}

impl E2e {
    fn from_env() -> Self {
        Self {
            path: std::env::var_os("LIGHTAGENT_DESKTOP_E2E_REPORT").map(PathBuf::from),
            started: Instant::now(),
            seen: Mutex::default(),
        }
    }

    fn note_once(&self, tag: &str, detail: &str) {
        let Some(path) = &self.path else { return };
        if !lock(&self.seen).insert(format!("{tag} {detail}")) {
            return;
        }
        let line = format!(
            "{tag} {detail} t_ms={}\n",
            self.started.elapsed().as_millis()
        );
        if let Ok(mut file) = std::fs::OpenOptions::new()
            .create(true)
            .append(true)
            .open(path)
        {
            let _ = file.write_all(line.as_bytes());
        }
    }
}

#[derive(Serialize)]
struct RuntimeStatus {
    state: &'static str,
    detail: Option<String>,
    desktop_version: &'static str,
    runtime_version: Option<String>,
    profile: Option<String>,
    capabilities: Vec<String>,
}

#[tauri::command]
fn runtime_status(host: tauri::State<'_, Arc<Host>>) -> RuntimeStatus {
    let mut status = RuntimeStatus {
        state: "starting",
        detail: None,
        desktop_version: VERSION,
        runtime_version: None,
        profile: None,
        capabilities: Vec::new(),
    };
    match &*lock(&host.runtime) {
        Runtime::Starting => {}
        Runtime::Ready(sidecar) => {
            status.state = "ready";
            status.runtime_version = Some(sidecar.handshake.version.clone());
            status.profile = sidecar.handshake.profile.clone();
            status.capabilities = sidecar.handshake.capabilities.clone();
        }
        Runtime::Failed(reason) => {
            status.state = "failed";
            status.detail = Some(reason.clone());
        }
        Runtime::Mismatch { expected, found } => {
            status.state = "mismatch";
            status.detail = Some(format!(
                "this app needs runtime {expected}; the bundled runtime reported {found}"
            ));
            status.runtime_version = Some(found.clone());
        }
        Runtime::Duplicate => {
            status.state = "duplicate";
            status.detail = Some(
                "Lightagent Desktop is already open. Use that window; this one does not start a second runtime on the same data."
                    .to_owned(),
            );
        }
    }
    status
}

/// Restart the runtime on request (a crashed or failed one, or a running one).
#[tauri::command]
fn runtime_restart(host: tauri::State<'_, Arc<Host>>) -> Result<(), String> {
    let previous = {
        let mut runtime = lock(&host.runtime);
        if matches!(*runtime, Runtime::Starting | Runtime::Duplicate) {
            return Err("the runtime cannot be restarted right now".to_owned());
        }
        std::mem::replace(&mut *runtime, Runtime::Starting)
    };
    let host = Arc::clone(host.inner());
    std::thread::spawn(move || {
        // Stopping the old runtime may take its grace period; not on the UI's thread.
        drop(previous);
        start_runtime(&host, true);
    });
    Ok(())
}

/// The runtime's most recent output lines (already redacted), for diagnostics.
#[tauri::command]
fn runtime_logs(host: tauri::State<'_, Arc<Host>>, limit: usize) -> Vec<String> {
    match &*lock(&host.runtime) {
        Runtime::Ready(sidecar) => {
            let logs = lock(&sidecar.logs);
            let skip = logs.len().saturating_sub(limit.min(500));
            logs.iter().skip(skip).cloned().collect()
        }
        _ => {
            let logs = lock(&host.last_logs);
            let skip = logs.len().saturating_sub(limit.min(500));
            logs.iter().skip(skip).cloned().collect()
        }
    }
}

#[derive(Serialize)]
struct FetchResult {
    status: u16,
    content_type: String,
    body: String,
}

fn valid_filename(name: &str) -> bool {
    !name.is_empty()
        && name.len() <= 180
        && name != "."
        && name != ".."
        && name
            .chars()
            .all(|c| c.is_ascii_alphanumeric() || matches!(c, '.' | '_' | ' ' | '-'))
}

#[tauri::command]
async fn api_fetch(
    host: tauri::State<'_, Arc<Host>>,
    method: String,
    target: String,
    body: Option<String>,
    body_base64: Option<String>,
    filename: Option<String>,
) -> Result<FetchResult, String> {
    let operation = host.contract.resolve(&method, &target)?.clone();
    if operation.stream {
        return Err(format!(
            "{} is a stream; subscribe to it instead",
            operation.id
        ));
    }
    let (base, authorization) = host.connection()?;
    let verb =
        reqwest::Method::from_bytes(method.as_bytes()).map_err(|_| "invalid method".to_owned())?;
    let mut request = host
        .http
        .request(verb, format!("{base}{target}"))
        .header(reqwest::header::AUTHORIZATION, authorization);
    if operation.raw_body {
        let bytes = base64::engine::general_purpose::STANDARD
            .decode(body_base64.unwrap_or_default())
            .map_err(|_| "the attachment is not valid base64".to_owned())?;
        let filename = filename
            .filter(|name| valid_filename(name))
            .ok_or("an attachment needs a plain file name")?;
        request = request
            .header("X-Lightagent-Filename", filename)
            .body(bytes);
    } else if let Some(body) = body {
        request = request
            .header(reqwest::header::CONTENT_TYPE, "application/json")
            .body(body);
    }
    let response = request
        .send()
        .await
        .map_err(|error| format!("the runtime did not answer: {}", error.without_url()))?;
    let status = response.status().as_u16();
    let content_type = response
        .headers()
        .get(reqwest::header::CONTENT_TYPE)
        .and_then(|value| value.to_str().ok())
        .unwrap_or("")
        .to_owned();
    let body = response
        .text()
        .await
        .map_err(|error| format!("the runtime's answer was cut off: {}", error.without_url()))?;
    if (200..300).contains(&status) {
        host.e2e.note_once("API_OK", &operation.id);
    }
    Ok(FetchResult {
        status,
        content_type,
        body,
    })
}

#[tauri::command]
async fn api_subscribe(host: tauri::State<'_, Arc<Host>>, target: String) -> Result<u64, String> {
    let operation = host.contract.resolve("GET", &target)?;
    if !operation.stream {
        return Err(format!("{} is not a stream", operation.id));
    }
    let (base, authorization) = host.connection()?;
    let request = host
        .http
        .get(format!("{base}{target}"))
        .header(reqwest::header::AUTHORIZATION, authorization)
        .header(reqwest::header::ACCEPT, "text/event-stream");
    let id = host.next_subscription.fetch_add(1, Ordering::Relaxed);
    let subscription = Arc::new(Subscription::default());
    lock(&host.subscriptions).insert(id, Arc::clone(&subscription));
    let relay = Arc::clone(&subscription);
    let task = tauri::async_runtime::spawn(async move {
        let outcome = relay_stream(request, &relay).await;
        {
            let mut state = lock(&relay.state);
            state.closed = true;
            state.error = outcome.err();
        }
        relay.notify.notify_waiters();
    });
    *lock(&subscription.task) = Some(task);
    Ok(id)
}

async fn relay_stream(
    request: reqwest::RequestBuilder,
    subscription: &Subscription,
) -> Result<(), String> {
    let response = request
        .send()
        .await
        .map_err(|error| format!("the runtime did not answer: {}", error.without_url()))?;
    if !response.status().is_success() {
        return Err(format!(
            "the runtime refused the stream ({})",
            response.status().as_u16()
        ));
    }
    let mut parser = sse::SseParser::default();
    let mut stream = response.bytes_stream();
    while let Some(chunk) = stream.next().await {
        let chunk = chunk.map_err(|error| format!("the stream broke: {}", error.without_url()))?;
        let events = parser.push(&chunk);
        if !events.is_empty() {
            lock(&subscription.state).events.extend(events);
            subscription.notify.notify_waiters();
        }
    }
    Ok(())
}

#[derive(Serialize)]
struct PollResult {
    events: Vec<sse::SseEvent>,
    closed: bool,
    error: Option<String>,
}

fn drain(state: &mut SubscriptionState) -> PollResult {
    let events: Vec<_> = state.events.drain(..).collect();
    PollResult {
        events,
        closed: state.closed,
        error: state.error.clone(),
    }
}

#[tauri::command]
async fn api_events_poll(
    host: tauri::State<'_, Arc<Host>>,
    subscription: u64,
    wait_ms: u64,
) -> Result<PollResult, String> {
    let entry = lock(&host.subscriptions)
        .get(&subscription)
        .cloned()
        .ok_or("unknown subscription")?;
    // Register for a wake-up before looking, so an event that lands in
    // between is never missed.
    let mut notified = std::pin::pin!(entry.notify.notified());
    notified.as_mut().enable();
    let ready = {
        let state = lock(&entry.state);
        !state.events.is_empty() || state.closed
    };
    if !ready {
        let _ = tokio::time::timeout(Duration::from_millis(wait_ms).min(MAX_POLL), notified).await;
    }
    let result = drain(&mut lock(&entry.state));
    if result.closed {
        lock(&host.subscriptions).remove(&subscription);
    }
    Ok(result)
}

#[tauri::command]
fn api_unsubscribe(host: tauri::State<'_, Arc<Host>>, subscription: u64) {
    if let Some(entry) = lock(&host.subscriptions).remove(&subscription)
        && let Some(task) = lock(&entry.task).take()
    {
        task.abort();
    }
}

#[tauri::command]
fn e2e_note(host: tauri::State<'_, Arc<Host>>, note: String) -> Result<(), String> {
    match note.as_str() {
        "ui_ready" => host.e2e.note_once("UI_READY", ""),
        "ui_error" => host.e2e.note_once("UI_ERROR", ""),
        _ => return Err("unknown note".to_owned()),
    }
    Ok(())
}

fn start_runtime(host: &Host, restart: bool) {
    let launched = sidecar::bundled_binary()
        .map_err(sidecar::LaunchError::Failed)
        .and_then(|binary| sidecar::launch(&binary, None, VERSION));
    let next = match launched {
        Ok(sidecar) => {
            host.e2e.note_once(
                if restart { "RUNTIME_RESTARTED" } else { "RUNTIME_READY" },
                &format!("version={}", sidecar.handshake.version),
            );
            Runtime::Ready(sidecar)
        }
        Err(sidecar::LaunchError::Failed(reason)) => {
            host.e2e.note_once("RUNTIME_FAILED", "");
            Runtime::Failed(reason)
        }
        Err(sidecar::LaunchError::Mismatch { expected, found }) => {
            host.e2e.note_once(
                "HANDSHAKE_MISMATCH",
                &format!("expected={expected} found={found}"),
            );
            Runtime::Mismatch { expected, found }
        }
    };
    *lock(&host.runtime) = next;
}

/// Crash detection: a runtime that exits while the host still wants it is
/// reported, its output kept, and it is restarted at most once per
/// [`AUTO_RESTART_WINDOW`].
fn watch_runtime(host: &Host) {
    loop {
        std::thread::sleep(WATCH_INTERVAL);
        let exited = match &mut *lock(&host.runtime) {
            Runtime::Ready(sidecar) => sidecar.exit_status().map(|status| {
                let logs: Vec<String> = lock(&sidecar.logs).iter().cloned().collect();
                (status, logs)
            }),
            _ => None,
        };
        let Some((status, logs)) = exited else { continue };
        host.e2e.note_once("RUNTIME_EXITED", "");
        *lock(&host.last_logs) = logs;
        *lock(&host.runtime) =
            Runtime::Failed(format!("the runtime stopped unexpectedly ({status})"));
        let allowed = {
            let mut last = lock(&host.last_auto_restart);
            let allowed = last.is_none_or(|at| at.elapsed() >= AUTO_RESTART_WINDOW);
            if allowed {
                *last = Some(Instant::now());
            }
            allowed
        };
        if allowed {
            *lock(&host.runtime) = Runtime::Starting;
            start_runtime(host, true);
        }
    }
}

/// Claim this app's single-instance lock. `Ok(None)`: another instance holds it.
fn claim_instance(dir: Option<PathBuf>) -> Result<Option<std::fs::File>, String> {
    let dir = dir.ok_or("the app has no data directory")?;
    std::fs::create_dir_all(&dir).map_err(|error| error.to_string())?;
    let file = std::fs::OpenOptions::new()
        .create(true)
        .truncate(false)
        .write(true)
        .open(dir.join("instance.lock"))
        .map_err(|error| error.to_string())?;
    match file.try_lock() {
        Ok(()) => Ok(Some(file)),
        Err(std::fs::TryLockError::WouldBlock) => Ok(None),
        Err(std::fs::TryLockError::Error(error)) => Err(error.to_string()),
    }
}

fn main() {
    let contract = match contract::Contract::load() {
        Ok(contract) => contract,
        Err(error) => {
            eprintln!("{error}");
            std::process::exit(1);
        }
    };
    // Loopback only: never through a proxy from the environment, and never
    // following a redirect that would carry the credential elsewhere.
    let http = match reqwest::Client::builder()
        .no_proxy()
        .redirect(reqwest::redirect::Policy::none())
        .connect_timeout(Duration::from_secs(5))
        .build()
    {
        Ok(http) => http,
        Err(error) => {
            eprintln!("could not build the HTTP client: {error}");
            std::process::exit(1);
        }
    };
    let host = Arc::new(Host {
        contract,
        runtime: Mutex::new(Runtime::Starting),
        http,
        subscriptions: Mutex::default(),
        next_subscription: AtomicU64::new(1),
        e2e: E2e::from_env(),
        last_auto_restart: Mutex::new(None),
        last_logs: Mutex::default(),
        instance: Mutex::new(None),
    });
    let app = tauri::Builder::default()
        .manage(Arc::clone(&host))
        .invoke_handler(tauri::generate_handler![
            runtime_status,
            runtime_logs,
            runtime_restart,
            api_fetch,
            api_subscribe,
            api_events_poll,
            api_unsubscribe,
            e2e_note
        ])
        .on_page_load(|webview, payload| {
            if matches!(payload.event(), tauri::webview::PageLoadEvent::Finished)
                && let Some(host) = webview.try_state::<Arc<Host>>()
            {
                host.e2e.note_once("PAGE_LOADED", "");
            }
        })
        .setup(|app| {
            let host = Arc::clone(app.state::<Arc<Host>>().inner());
            match claim_instance(app.path().app_local_data_dir().ok()) {
                Ok(Some(lock_file)) => *lock(&host.instance) = Some(lock_file),
                Ok(None) => {
                    host.e2e.note_once("DUPLICATE_INSTANCE", "");
                    *lock(&host.runtime) = Runtime::Duplicate;
                    return Ok(());
                }
                // Without a lock the app still runs; the runtime's own
                // atomic writes remain the guard against a second writer.
                Err(error) => eprintln!("single-instance lock unavailable: {error}"),
            }
            std::thread::spawn(move || {
                start_runtime(&host, false);
                watch_runtime(&host);
            });
            Ok(())
        })
        .build(tauri::generate_context!());
    let app = match app {
        Ok(app) => app,
        Err(error) => {
            eprintln!("could not start the window: {error}");
            std::process::exit(1);
        }
    };
    app.run(|app, event| {
        if let tauri::RunEvent::Exit = event
            && let Some(host) = app.try_state::<Arc<Host>>()
        {
            host.stop_runtime();
        }
    });
}
=== write desktop/src-tauri/src/sidecar.rs
//! Launching and owning the bundled runtime.
//!
//! The host starts exactly one binary: the `lightagent-sidecar` shipped next
//! to its own executable (never one found on `PATH`). The per-launch key is a
//! fresh 256-bit value from the OS generator, written once as the first line
//! of the child's stdin; it never appears in argv, the environment, a URL, a
//! file, a log line, or the UI. The host then holds stdin open as the child's
//! lifeline: however the host ends, even killed, the pipe closes and the
//! runtime exits. The child answers with one JSON handshake line on stdout,
//! and is refused unless its protocol and version match this build.

use std::collections::VecDeque;
use std::io::{BufRead as _, BufReader, Read, Write as _};
use std::path::{Path, PathBuf};
use std::process::{Child, ChildStdin, Command, Stdio};
use std::sync::mpsc;
use std::sync::{Arc, Mutex};
use std::time::Duration;

use serde::Deserialize;

/// How long a starting runtime may take to report ready.
pub const READY_TIMEOUT: Duration = Duration::from_secs(20);
/// How long a stopping runtime may take after its lifeline closes.
const STOP_GRACE: Duration = Duration::from_secs(5);
/// Lines of runtime output kept in memory for diagnostics.
const LOG_LINES: usize = 2_000;

/// The one line a runtime prints when it is ready.
#[derive(Clone, Debug, Deserialize)]
pub struct Handshake {
    pub lightagent: String,
    pub protocol: u32,
    pub version: String,
    pub addr: String,
    #[serde(default)]
    pub profile: Option<String>,
    #[serde(default)]
    pub capabilities: Vec<String>,
}

/// Why a runtime did not become usable.
#[derive(Debug)]
pub enum LaunchError {
    Failed(String),
    Mismatch { expected: String, found: String },
}

/// A running, owned runtime.
pub struct Sidecar {
    child: Child,
    lifeline: Option<ChildStdin>,
    key: String,
    pub handshake: Handshake,
    pub logs: Arc<Mutex<VecDeque<String>>>,
}

impl Sidecar {
    pub fn base_url(&self) -> String {
        format!("http://{}", self.handshake.addr)
    }

    pub fn authorization(&self) -> String {
        format!("Bearer {}", self.key)
    }

    /// How the runtime ended, if it has: the host's crash detection.
    pub fn exit_status(&mut self) -> Option<String> {
        match self.child.try_wait() {
            Ok(Some(status)) => Some(status.to_string()),
            Ok(None) => None,
            Err(error) => Some(format!("unknown ({error})")),
        }
    }

    /// Stop the runtime this host started, and nothing else.
    pub fn stop(&mut self) {
        // Closing the lifeline asks the runtime to finish; kill only if it
        // has not within the grace period.
        drop(self.lifeline.take());
        let deadline = std::time::Instant::now() + STOP_GRACE;
        while std::time::Instant::now() < deadline {
            if matches!(self.child.try_wait(), Ok(Some(_))) {
                return;
            }
            std::thread::sleep(Duration::from_millis(50));
        }
        let _ = self.child.kill();
        let _ = self.child.wait();
    }
}

impl Drop for Sidecar {
    fn drop(&mut self) {
        self.stop();
        // Overwrite the key before its memory is released.
        let len = self.key.len();
        self.key.clear();
        self.key.extend(std::iter::repeat_n('0', len));
    }
}

/// The bundled runtime: next to the host's own executable.
pub fn bundled_binary() -> Result<PathBuf, String> {
    let exe = std::env::current_exe().map_err(|error| format!("cannot locate the app: {error}"))?;
    let dir = exe.parent().ok_or("the app has no directory")?;
    let name = if cfg!(windows) {
        "lightagent-sidecar.exe"
    } else {
        "lightagent-sidecar"
    };
    let path = dir.join(name);
    if path.is_file() {
        Ok(path)
    } else {
        Err(format!(
            "the bundled runtime is missing ({name} next to the app)"
        ))
    }
}

fn new_key() -> Result<String, String> {
    let mut bytes = [0u8; 32];
    getrandom::fill(&mut bytes).map_err(|_| "the OS random source is unavailable".to_owned())?;
    Ok(bytes.iter().map(|byte| format!("{byte:02x}")).collect())
}

/// Start `binary` as an owned runtime for `profile` and wait for its handshake.
pub fn launch(
    binary: &Path,
    profile: Option<&str>,
    expected_version: &str,
) -> Result<Sidecar, LaunchError> {
    let key = new_key().map_err(LaunchError::Failed)?;
    let mut command = Command::new(binary);
    command
        .args(["serve", "--desktop", "--host", "127.0.0.1", "--port", "0"])
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped());
    if let Some(profile) = profile {
        command.arg("--profile").arg(profile);
    }
    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt as _;
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        command.creation_flags(CREATE_NO_WINDOW);
    }
    let mut child = command
        .spawn()
        .map_err(|error| LaunchError::Failed(format!("could not start the runtime: {error}")))?;

    // Deliver the key, then keep stdin open as the runtime's lifeline.
    let lifeline = child.stdin.take().and_then(|mut stdin| {
        stdin
            .write_all(format!("{key}\n").as_bytes())
            .and_then(|()| stdin.flush())
            .ok()
            .map(|()| stdin)
    });
    let Some(lifeline) = lifeline else {
        let _ = child.kill();
        let _ = child.wait();
        return Err(LaunchError::Failed(
            "could not hand the runtime its credential".to_owned(),
        ));
    };

    let logs = Arc::new(Mutex::new(VecDeque::with_capacity(LOG_LINES)));
    let (ready_tx, ready_rx) = mpsc::channel::<String>();
    if let Some(stdout) = child.stdout.take() {
        let logs = Arc::clone(&logs);
        let key = key.clone();
        std::thread::spawn(move || pump(stdout, &logs, &key, Some(ready_tx)));
    }
    if let Some(stderr) = child.stderr.take() {
        let logs = Arc::clone(&logs);
        let key = key.clone();
        std::thread::spawn(move || pump(stderr, &logs, &key, None));
    }

    let line = match ready_rx.recv_timeout(READY_TIMEOUT) {
        Ok(line) => line,
        Err(error) => {
            let _ = child.kill();
            let _ = child.wait();
            return Err(LaunchError::Failed(match error {
                mpsc::RecvTimeoutError::Timeout => format!(
                    "the runtime did not report ready within {} s",
                    READY_TIMEOUT.as_secs()
                ),
                mpsc::RecvTimeoutError::Disconnected => {
                    "the runtime exited before reporting ready".to_owned()
                }
            }));
        }
    };
    let handshake: Handshake = match serde_json::from_str(&line) {
        Ok(handshake) => handshake,
        Err(_) => {
            let _ = child.kill();
            let _ = child.wait();
            return Err(LaunchError::Failed(
                "the runtime's ready line is not a handshake".to_owned(),
            ));
        }
    };
    let mut sidecar = Sidecar {
        child,
        lifeline: Some(lifeline),
        key,
        handshake,
        logs,
    };
    if sidecar.handshake.lightagent != "serve"
        || sidecar.handshake.protocol != crate::contract::PROTOCOL
    {
        let found = format!(
            "{} protocol {}",
            sidecar.handshake.lightagent, sidecar.handshake.protocol
        );
        sidecar.stop();
        return Err(LaunchError::Mismatch {
            expected: format!("serve protocol {}", crate::contract::PROTOCOL),
            found,
        });
    }
    if sidecar.handshake.version != expected_version {
        let found = sidecar.handshake.version.clone();
        sidecar.stop();
        return Err(LaunchError::Mismatch {
            expected: expected_version.to_owned(),
            found,
        });
    }
    if !is_loopback_addr(&sidecar.handshake.addr) {
        sidecar.stop();
        return Err(LaunchError::Failed(
            "the runtime is not bound to 127.0.0.1".to_owned(),
        ));
    }
    Ok(sidecar)
}

fn is_loopback_addr(addr: &str) -> bool {
    addr.strip_prefix("127.0.0.1:")
        .is_some_and(|port| !port.is_empty() && port.bytes().all(|byte| byte.is_ascii_digit()))
}

/// Copy one output stream into the bounded log, redacting the key should it
/// ever appear, and hand the first stdout line to the launcher.
fn pump(
    stream: impl Read,
    logs: &Mutex<VecDeque<String>>,
    key: &str,
    mut ready: Option<mpsc::Sender<String>>,
) {
    for line in BufReader::new(stream).lines() {
        let Ok(line) = line else { break };
        let line = line.replace(key, "<redacted>");
        if let Some(sender) = ready.take() {
            let _ = sender.send(line.clone());
        }
        if let Ok(mut logs) = logs.lock() {
            if logs.len() == LOG_LINES {
                logs.pop_front();
            }
            logs.push_back(line);
        }
    }
}

"""Unattended desktop end-to-end checks on a GitHub-hosted runner.

Usage: python run.py <out-dir> <mode> -- <app command...>

Modes:
  ready      the runtime starts, the UI loads and makes its first API call
  mismatch   a runtime reporting another version is refused, with the error screen
  crash      the runtime is killed under a ready app: the host reports it,
             restarts it once, and the UI is ready again
  duplicate  a second launch finds the first instance, starts no runtime, and
             says so; the first instance keeps running

Every mode screenshots the window and checks that no 256-bit hex value (the
shape of the launch key) appears in any argv or readable environment of the
app's process tree, or in the host's report. Then the host is terminated the
way a crash would end it, and the runtime must follow it within 10 s when
E2E_REQUIRE_NO_ORPHAN=1. Writes e2e-<mode>.json; exits non-zero when an
expectation is not met.
"""

import json
import os
import re
import subprocess
import sys
import time

import psutil

KEY_SHAPE = re.compile(r"\b[0-9a-f]{64}\b")
READY = ["RUNTIME_READY", "PAGE_LOADED", "UI_READY", "API_OK sessions.list"]


def screenshot(path):
    try:
        if sys.platform == "darwin":
            subprocess.run(["screencapture", "-x", path], check=True, timeout=30)
        elif sys.platform.startswith("linux"):
            subprocess.run(["import", "-window", "root", path], check=True, timeout=30)
        else:
            from PIL import ImageGrab

            ImageGrab.grab().save(path)
        return True
    except Exception as error:
        print(f"screenshot failed: {error}")
        return False


def tree(pid):
    try:
        root = psutil.Process(pid)
        return [root] + root.children(recursive=True)
    except psutil.Error:
        return []


def read(path):
    return open(path, encoding="utf-8").read() if os.path.exists(path) else ""


def launch(command, report):
    if os.path.exists(report):
        os.remove(report)
    return subprocess.Popen(command, env=dict(os.environ, LIGHTAGENT_DESKTOP_E2E_REPORT=report))


def wait_for(report, tags, process, started, seen, timeout=90):
    """Record when each tag first appears in the report."""
    deadline = time.time() + timeout
    while time.time() < deadline and process.poll() is None:
        lines = read(report).splitlines()
        for tag in tags:
            if tag not in seen and any(line.startswith(tag) for line in lines):
                seen[tag] = round(time.time() - started, 3)
        if all(tag in seen for tag in tags):
            return
        time.sleep(0.1)


def leaks_in(processes, *reports):
    found = []
    for process in processes:
        try:
            if KEY_SHAPE.search(" ".join(process.cmdline())):
                found.append(f"argv of {process.name()}")
        except psutil.Error:
            pass
        try:
            if any(KEY_SHAPE.search(value) for value in process.environ().values()):
                found.append(f"environment of {process.name()}")
        except psutil.Error:
            pass  # not readable on every OS
    for report in reports:
        if KEY_SHAPE.search(read(report)):
            found.append(os.path.basename(report))
    return found


def runtimes(processes):
    return [p for p in processes if "sidecar" in p.name()]


def stop(process):
    process.terminate()
    try:
        process.wait(timeout=15)
    except subprocess.TimeoutExpired:
        process.kill()


def main():
    out = os.path.abspath(sys.argv[1])
    mode = sys.argv[2]
    command = sys.argv[sys.argv.index("--") + 1:]
    os.makedirs(out, exist_ok=True)
    report = os.path.join(out, f"report-{mode}.txt")
    started = time.time()
    seen = {}
    want = list(READY)
    extra = {}

    app = launch(command, report)
    if mode == "mismatch":
        want = ["HANDSHAKE_MISMATCH", "PAGE_LOADED", "UI_ERROR"]
        wait_for(report, want, app, started, seen)
    else:
        wait_for(report, READY, app, started, seen)

    second = None
    second_report = os.path.join(out, "report-duplicate-second.txt")
    if mode == "crash" and all(tag in seen for tag in READY):
        victims = runtimes(tree(app.pid))
        extra["killed_runtime_pids"] = [p.pid for p in victims]
        for victim in victims:
            victim.kill()
        want += ["RUNTIME_EXITED", "RUNTIME_RESTARTED"]
        wait_for(report, ["RUNTIME_EXITED", "RUNTIME_RESTARTED"], app, started, seen)
    elif mode == "duplicate" and all(tag in seen for tag in READY):
        second = launch(command, second_report)
        second_seen = {}
        wait_for(second_report, ["DUPLICATE_INSTANCE", "PAGE_LOADED", "UI_ERROR"], second, started, second_seen)
        extra["second_instance"] = second_seen
        extra["second_started_a_runtime"] = bool(runtimes(tree(second.pid)))
        extra["first_still_running"] = app.poll() is None
        for tag in ("DUPLICATE_INSTANCE", "UI_ERROR"):
            if tag in second_seen:
                seen[f"second:{tag}"] = second_seen[tag]
        want += ["second:DUPLICATE_INSTANCE", "second:UI_ERROR"]

    time.sleep(2)
    result = {"mode": mode, "milestones_s": seen, "missing": [t for t in want if t not in seen], **extra}
    result["screenshot"] = screenshot(os.path.join(out, f"screenshot-{mode}.png"))
    processes = tree(app.pid) + (tree(second.pid) if second else [])
    result["processes"] = sorted({p.name() for p in processes if p.is_running()})
    result["key_leaks"] = leaks_in(processes, report, second_report)
    result["report"] = read(report).splitlines()

    owned = runtimes(processes)
    if second:
        stop(second)
    stop(app)
    deadline = time.time() + 10
    while time.time() < deadline and any(p.is_running() for p in owned):
        time.sleep(0.2)
    survivors = [p for p in owned if p.is_running()]
    result["runtime_survived_host_termination"] = bool(survivors)
    for process in survivors:
        process.kill()

    with open(os.path.join(out, f"e2e-{mode}.json"), "w", encoding="utf-8") as handle:
        json.dump(result, handle, indent=1)
    print(json.dumps(result, indent=1))
    failed = bool(result["missing"] or result["key_leaks"])
    failed |= bool(survivors) and os.environ.get("E2E_REQUIRE_NO_ORPHAN") == "1"
    failed |= mode == "duplicate" and (extra.get("second_started_a_runtime") or not extra.get("first_still_running"))
    return 1 if failed else 0


if __name__ == "__main__":
    sys.exit(main())

### Audit findings that shape D1–D3

1. **The process model exists.** `lightagent serve` (`crates/lightagent/src/serve.rs:732`)
   serves `/api/lightagent/v1` (21 method/route pairs, `crates/lightagent-api/src/lib.rs:73-112`)

2. **The API covers only part of the CLI.** It has no operation for config
   path/get/set and the Jev routing report, models, profile
   show/create/use/preset/delete, the extensions commands, worker
   assign/revoke, memory, RAG, identity, remote credentials, import, doctor,
   init/setup, onboard, reload, **continue** (resume after the time budget), or
   **steering** (input queued while a run is in progress).
3. **CLI handlers are print-bound.** They have the shape
   `fn(args…, json: bool) -> Result<(), String>` and print their results
   (for example `extensions.rs:27`, `rag.rs:697`, `import.rs:28`, `memory.rs`).
   Typed shared operations must be extracted (D3) so CLI, API, and desktop call
   the same code.
4. **Loopback is unauthenticated.** `serve.rs:746-758`: with no `--key-env`,
   a loopback bind uses `AuthConfig::open()`. `crates/lightagent-api` has no
   Host or Origin validation, so a DNS-rebinding page or any local process can
   drive tools. This is an input to the D1 security design.
5. **One profile per server process.** `AppState.session_profile` is fixed
   at start (`serve.rs:739-760`). `POST /runs {profile}` is honoured only in
   multi-user mode (`lib.rs:1148-1160`). The active-profile write
   `ProfileStore::set_active` is atomic (temp file + rename,
   `paths.rs:173-185`), but no lock coordinates a running server with a CLI
   that switches profile. This is an input to the D1 profile-switch decision.
6. **Secret authority.** Provider keys are stored in owner-only
   `~/.lightagent/secrets` and referenced as `SecretRef`. The
   remote-credential vault is sealed with
   `LIGHTAGENT_CREDENTIAL_KEY[_FILE]`. Identity secrets have strict delivery
   rules (`identity_admin.rs:10-14`).

   The 10.14 floor is a declared deployment target; no hosted runner executes

## D3a — The real runtime in desktop mode

- `lightagent serve --desktop [--profile <id>]` (`crates/lightagent/src/serve.rs`, `run_desktop`):
  - loopback only;
  - the key is the first line of stdin, and the rest of stdin is the **lifeline**: on EOF, graceful shutdown, then exit within 5 s;
  - scaffolds an empty home and the protected `default` profile on first start;
  - writes one JSON handshake line to stdout and nothing else there;
  - serves no Web UI.
- `lightagent_api::desktop` is the guard on every route, including `/health`
  (otherwise unauthenticated) and the event stream. It checks the exact
  `Host`, refuses any `Origin` and any `Sec-Fetch-Site` other than `none`,
  and compares the Bearer key in constant time. Each refusal has its own
  category. Unit tests cover the guard; `crates/lightagent/tests/desktop_serve.rs`
  drives the real binary over raw TCP (no key, wrong key, other Host, Origin,
  cross-site, `/health`, SSE, no Web UI, lifeline exit, refused binds and a
  missing key).
- Host:
  - `--parent-pid` is gone (the real CLI never had it); the host keeps stdin open as the lifeline;
  - `stop()` closes the lifeline, then waits up to 5 s before killing.

  The mock got the same lifeline.
- The shell CI bundles the real `lightagent` (built `--locked` in the root
  workspace) with an isolated `LIGHTAGENT_HOME`. The ready e2e now **fails**
  if the runtime outlives a terminated host (`E2E_REQUIRE_NO_ORPHAN=1`).
  Version mismatch is still proven by swapping in the mock. Linux also runs
  under `dbus-run-session` to test the D-Bus hypothesis for the 30 s delay.
- Inventory: two host-owned rows (`serve --desktop` and `--profile`); 308 rows; denominator unchanged at 226.
- Architecture §4 and §6 were updated: the stdin lifeline replaces `--parent-pid`, with the reasons.

## D3b — Host lifecycle

- **Crash detection:**
  - the host checks its runtime every 0.5 s;
  - an unexpected exit is reported (`failed`, with the exit status), and its output is kept for diagnostics;
  - the runtime is restarted automatically **at most once per 60 s**, so a runtime that keeps failing stays down and says so.
- **`runtime_restart`** (user-initiated) and `runtime_logs`, which also shows the last crashed runtime's output.
- **Single instance:**
  - an exclusive lock (`std::fs::File::try_lock`, no new crates) on `instance.lock` in the app's local data directory, held for the app's lifetime;
  - a second launch starts **no runtime** and explains itself;
  - the OS releases the lock if the app dies.
- **UI (`DesktopGate`):**
  - keeps watching after start-up; a stopped runtime shows a modal notice over the kept, inert app;
  - failures offer **Restart runtime** and a **Runtime log** disclosure;
  - duplicate, mismatch and failure each state their cause and remedy.
- **CI:** e2e modes `crash` (kill the runtime under a ready app; require the
  exit to be reported and a restart) and `duplicate` (second launch; require
  no second runtime and the first still running), both with
  `E2E_REQUIRE_NO_ORPHAN=1`. Linux runs under a session bus by default.
- **Deferred to D4a:** a close with active runs (warn, or cancel then quit),
  which needs the active-runs operation.
