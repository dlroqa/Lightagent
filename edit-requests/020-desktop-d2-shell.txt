Desktop D2: Tauri shell, IPC transport, operation contract and hosted shell CI

Adds the desktop/ workspace: a Tauri 2 host that owns one runtime (stdin
launch key, handshake and version check, contract allowlist, SSE relay,
no proxy and no redirects) and a std-only mock runtime with the same
Host/Origin/Bearer checks. The frontend gains a transport that uses IPC in
the desktop build and is unchanged in the browser, plus a start-up gate.
The operation contract is checked against the server routes and the UI
client. desktop.yml builds, lints, tests and bundles the shell on four
targets and runs end-to-end checks for readiness, version mismatch and
launch-key leaks.

#!/usr/bin/env python3
"""Keep the desktop operation contract equal to the server and the UI client.

docs/desktop/contract/operations.json is the allowlist the desktop host
enforces for every UI request (desktop/src-tauri/src/contract.rs embeds it).
It must:

  * list exactly the routes `lightagent_api::router` serves (method + path),
    so the host can never forward something the server lacks, and every
    server route is either reachable or deliberately added here;
  * cover every path the frontend client (frontend/src/api/agent.ts) calls.

The frontend check compares paths, not methods: the client builds requests
through helpers, and a wrong method is refused by the host at run time.
`--self-test` adds a server route and a client path in memory and requires
both to be reported.
"""

import importlib.util
import json
import os
import re
import sys

ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
BASE = "/api/lightagent/v1"


def load_inventory_module():
    path = os.path.join(ROOT, "scripts", "check-desktop-inventory.py")
    spec = importlib.util.spec_from_file_location("desktop_inventory", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def read(rel):
    with open(os.path.join(ROOT, rel), encoding="utf-8") as handle:
        return handle.read()


def shape(path):
    """A path with every parameter collapsed to `{}`, relative to the API base."""
    if path.startswith(BASE):
        path = path[len(BASE):]
    return re.sub(r"\{[^}]*\}", "{}", path)


def client_paths(text):
    text = text.replace("${BASE}", "")
    found = set()
    for literal in re.findall(r'[`"](/[^`"\s]*)[`"]', text):
        path = literal.split("?", 1)[0]
        path = re.sub(r"\$\{[^}]*\}", "{}", path)
        if path in ("", BASE):
            continue
        found.add(path)
    return found


def check(contract, server_text, client_text, scan_routes):
    errors = []
    ops = contract["operations"]
    ids = [op["id"] for op in ops]
    if len(ids) != len(set(ids)):
        errors.append("contract: duplicate operation id")
    for op in ops:
        if op["method"] not in ("GET", "POST", "PUT", "PATCH", "DELETE"):
            errors.append(f"contract: {op['id']} has method {op['method']!r}")
        if not op["path"].startswith("/"):
            errors.append(f"contract: {op['id']} path must start with '/'")
    listed = {f"{op['method']} {op['path']}" for op in ops}
    served = scan_routes(server_text)
    for item in sorted(served - listed):
        errors.append(f"server: {item} is served but not in the contract")
    for item in sorted(listed - served):
        errors.append(f"server: contract lists {item} but the server does not serve it")
    shapes = {shape(op["path"]) for op in ops}
    for path in sorted(client_paths(client_text) - shapes):
        errors.append(f"client: frontend calls {path} but no contract operation has that path")
    return errors


def main():
    inventory = load_inventory_module()
    with open(os.path.join(ROOT, "docs", "desktop", "contract", "operations.json"), encoding="utf-8") as handle:
        contract = json.load(handle)
    server = read("crates/lightagent-api/src/lib.rs")
    client = read("frontend/src/api/agent.ts")
    if "--self-test" in sys.argv:
        base = check(contract, server, client, inventory.scan_routes)
        if base:
            print("self-test needs a clean baseline:\n" + "\n".join(base))
            return 1
        added_route = server.replace('.route("/health", get(health))',
                                     '.route("/health", get(health))\n        .route("/api/lightagent/v1/memory", get(health))', 1)
        added_call = client + '\nconst probe = () => jsonRequest("/memory/search");\n'
        failures = 0
        for label, args, prefix in (("server route", (added_route, client), "server:"),
                                    ("client path", (server, added_call), "client:")):
            hit = [e for e in check(contract, args[0], args[1], inventory.scan_routes) if e.startswith(prefix)]
            print(f"self-test {label}: {'detected' if hit else 'MISSED'} {hit[:1]}")
            failures += 0 if hit else 1
        return 1 if failures else 0
    errors = check(contract, server, client, inventory.scan_routes)
    print(f"desktop operation contract: {len(contract['operations'])} operations, {len(errors)} errors")
    for error in errors:
        print(f"::error::{error}")
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main())

import { useEffect, useRef, useState, type ReactNode } from "react";

import { invoke, isDesktop } from "../api/transport";
import "./desktop-gate.css";

/** The desktop host's view of its bundled runtime (`runtime_status`). */
interface RuntimeStatus {
  state: "starting" | "ready" | "failed" | "mismatch";
  detail: string | null;
  desktop_version: string;
  runtime_version: string | null;
  profile: string | null;
}

/**
 * In the desktop app, hold the UI until the bundled runtime is ready, and
 * explain plainly when it cannot start. In the browser build this renders its
 * children directly.
 */
export function DesktopGate({ children }: { children: ReactNode }) {
  const [status, setStatus] = useState<RuntimeStatus | null>(null);
  const [hostError, setHostError] = useState<string | null>(null);
  const heading = useRef<HTMLHeadingElement>(null);

  useEffect(() => {
    if (!isDesktop) return;
    let stopped = false;
    let timer: number | undefined;
    const poll = async () => {
      try {
        const next = await invoke<RuntimeStatus>("runtime_status");
        if (stopped) return;
        setStatus(next);
        if (next.state === "starting") {
          timer = window.setTimeout(() => void poll(), 250);
        } else {
          void invoke("e2e_note", { note: next.state === "ready" ? "ui_ready" : "ui_error" }).catch(() => undefined);
        }
      } catch (cause) {
        if (!stopped) setHostError(cause instanceof Error ? cause.message : String(cause));
      }
    };
    void poll();
    return () => {
      stopped = true;
      if (timer !== undefined) window.clearTimeout(timer);
    };
  }, []);

  const failed = hostError !== null || status?.state === "failed" || status?.state === "mismatch";
  useEffect(() => {
    if (failed) heading.current?.focus();
  }, [failed]);

  if (!isDesktop || status?.state === "ready") return <>{children}</>;

  if (!failed) {
    return (
      <main className="desktop-gate" aria-busy="true">
        <div className="desktop-gate__panel" role="status" aria-live="polite">
          <span className="desktop-gate__pulse" aria-hidden="true" />
          <h1 className="desktop-gate__title">Starting Lightagent…</h1>
          <p className="desktop-gate__text">Starting the bundled runtime on this computer.</p>
        </div>
      </main>
    );
  }

  const mismatch = status?.state === "mismatch";
  return (
    <main className="desktop-gate">
      <div className="desktop-gate__panel desktop-gate__panel--error" role="alert">
        <h1 className="desktop-gate__title" tabIndex={-1} ref={heading}>
          {mismatch ? "The bundled runtime does not match this app" : "Lightagent could not start its runtime"}
        </h1>
        <p className="desktop-gate__text">
          {hostError ?? status?.detail ?? "The runtime stopped before it was ready."}
        </p>
        <p className="desktop-gate__text desktop-gate__text--muted">
          {mismatch
            ? "Reinstall Lightagent Desktop so the app and its runtime come from the same release. Nothing was run."
            : "Quit and reopen Lightagent. If it happens again, the runtime log in Settings → Diagnostics shows why."}
        </p>
        <dl className="desktop-gate__facts">
          <dt>App</dt>
          <dd>{status?.desktop_version ?? "unknown"}</dd>
          <dt>Runtime</dt>
          <dd>{status?.runtime_version ?? "not reported"}</dd>
        </dl>
      </div>
    </main>
  );
}

/**
 * How the UI reaches the Lightagent API.
 *
 * The browser build is served by `lightagent serve` itself, so it uses
 * same-origin `fetch` and `EventSource` unchanged. The desktop build
 * (`vite build --mode desktop`) has no network access at all: each request
 * goes to the desktop host over IPC, which checks it against the operation
 * contract (docs/desktop/contract/operations.json) and forwards it to the
 * runtime it owns, with a credential this code never sees.
 *
 * Both paths keep the same semantics, so `agent.ts` and `useRunEvents.ts`
 * (ordered event ids, gap detection, `?after=` replay) behave identically.
 */

type Invoke = <T>(command: string, args?: Record<string, unknown>) => Promise<T>;

export const isDesktop = import.meta.env.MODE === "desktop";

/** Call a desktop host command. Rejects outside the desktop app. */
export function invoke<T>(command: string, args?: Record<string, unknown>): Promise<T> {
  const tauri = (window as unknown as { __TAURI__?: { core?: { invoke?: Invoke } } }).__TAURI__;
  const call = tauri?.core?.invoke;
  if (!call) return Promise.reject(new Error("The desktop host is not available."));
  return call<T>(command, args);
}

interface HostResponse {
  status: number;
  content_type: string;
  body: string;
}

async function blobToBase64(blob: Blob): Promise<string> {
  const bytes = new Uint8Array(await blob.arrayBuffer());
  let binary = "";
  for (let start = 0; start < bytes.length; start += 0x8000) {
    binary += String.fromCharCode(...bytes.subarray(start, start + 0x8000));
  }
  return btoa(binary);
}

function requestTarget(input: RequestInfo | URL): string {
  const url = typeof input === "string" ? input : input instanceof URL ? input.href : input.url;
  if (/^[a-z]+:/i.test(url)) {
    const parsed = new URL(url);
    return parsed.pathname + parsed.search;
  }
  return url;
}

async function desktopFetch(input: RequestInfo | URL, init: RequestInit = {}): Promise<Response> {
  const headers = new Headers(init.headers);
  let body: string | null = null;
  let bodyBase64: string | null = null;
  if (init.body instanceof Blob) {
    bodyBase64 = await blobToBase64(init.body);
  } else if (typeof init.body === "string") {
    body = init.body;
  }
  const result = await invoke<HostResponse>("api_fetch", {
    method: (init.method ?? "GET").toUpperCase(),
    target: requestTarget(input),
    body,
    bodyBase64,
    filename: headers.get("X-Lightagent-Filename"),
  });
  const empty = result.status === 204 || result.status === 304;
  return new Response(empty ? null : result.body, {
    status: result.status,
    headers: { "content-type": result.content_type },
  });
}

interface HostEvent {
  id: string | null;
  event: string;
  data: string;
}

interface HostPoll {
  events: HostEvent[];
  closed: boolean;
  error: string | null;
}

/**
 * The `EventSource` surface `useRunEvents` relies on, fed by the host's relay.
 * Like a browser source that has given up, it reports `CLOSED` and `onerror`
 * when the stream ends without `close()`, so the hook resumes with `?after=`.
 */
class DesktopEventSource extends EventTarget {
  static readonly CONNECTING = 0;
  static readonly OPEN = 1;
  static readonly CLOSED = 2;

  readyState = DesktopEventSource.CONNECTING;
  onopen: ((event: Event) => void) | null = null;
  onerror: ((event: Event) => void) | null = null;
  private subscription: number | null = null;
  private stopped = false;

  constructor(readonly url: string) {
    super();
    void this.relay();
  }

  close(): void {
    this.stopped = true;
    this.readyState = DesktopEventSource.CLOSED;
    if (this.subscription !== null) {
      void invoke("api_unsubscribe", { subscription: this.subscription }).catch(() => undefined);
    }
  }

  private async relay(): Promise<void> {
    try {
      this.subscription = await invoke<number>("api_subscribe", { target: this.url });
      if (this.stopped) {
        this.close();
        return;
      }
      this.readyState = DesktopEventSource.OPEN;
      this.onopen?.(new Event("open"));
      while (!this.stopped) {
        const batch = await invoke<HostPoll>("api_events_poll", { subscription: this.subscription, waitMs: 20000 });
        for (const event of batch.events) {
          if (this.stopped) return;
          this.dispatchEvent(new MessageEvent(event.event, { data: event.data, lastEventId: event.id ?? "" }));
        }
        if (batch.closed) break;
      }
    } catch {
      // Reported through onerror below, exactly as a failed browser stream is.
    }
    if (!this.stopped) {
      this.readyState = DesktopEventSource.CLOSED;
      this.onerror?.(new Event("error"));
    }
  }
}

struct Request {
    method: String,
    path: String,
    headers: Vec<(String, String)>,
}

impl Request {
    fn header(&self, name: &str) -> Option<&str> {
        self.headers
            .iter()
            .find(|(key, _)| key.eq_ignore_ascii_case(name))
            .map(|(_, value)| value.as_str())
    }
}

fn read_request(stream: &TcpStream) -> std::io::Result<Request> {
    let mut reader = BufReader::new(stream);
    let mut line = String::new();
    reader.read_line(&mut line)?;
    let mut parts = line.split_whitespace();
    let method = parts.next().unwrap_or("").to_owned();
    let path = parts.next().unwrap_or("").to_owned();
    let mut headers = Vec::new();
    loop {
        let mut header = String::new();
        if reader.read_line(&mut header)? == 0 {
            break;
        }
        let header = header.trim_end();
        if header.is_empty() {
            break;
        }
        if let Some((name, value)) = header.split_once(':') {
            headers.push((name.trim().to_owned(), value.trim().to_owned()));
        }
    }
    let length = headers
        .iter()
        .find(|(name, _)| name.eq_ignore_ascii_case("content-length"))
        .and_then(|(_, value)| value.parse::<u64>().ok())
        .unwrap_or(0)
        .min(32 * 1024 * 1024);
    let mut body = Vec::new();
    reader.take(length).read_to_end(&mut body)?;
    Ok(Request { method, path, headers })
}

fn respond(mut stream: &TcpStream, status: &str, content_type: &str, body: &str) -> std::io::Result<()> {
    write!(
        stream,
        "HTTP/1.1 {status}\r\nContent-Type: {content_type}\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        body.len()
    )
}

fn serve(stream: TcpStream, host: &str, bearer: &str) -> std::io::Result<()> {
    stream.set_read_timeout(Some(Duration::from_secs(30)))?;
    let request = read_request(&stream)?;
    let json = "application/json";
    // The same three checks, in the same order, as the real desktop mode.
    if request.header("host") != Some(host) {
        return respond(&stream, "403 Forbidden", json, "{\"error\":{\"category\":\"host_rejected\"}}");
    }
    if request.header("origin").is_some() {
        return respond(&stream, "403 Forbidden", json, "{\"error\":{\"category\":\"origin_rejected\"}}");
    }
    if request.header("authorization") != Some(bearer) {
        return respond(&stream, "401 Unauthorized", json, "{\"error\":{\"category\":\"unauthenticated\"}}");
    }
    let path = request.path.split('?').next().unwrap_or("");
    let route = path.strip_prefix("/api/lightagent/v1").unwrap_or(path);
    if request.method == "GET" && route.starts_with("/runs/") && route.ends_with("/events") {
        let mut stream = &stream;
        write!(
            stream,
            "HTTP/1.1 200 OK\r\nContent-Type: text/event-stream\r\nCache-Control: no-cache\r\nConnection: close\r\n\r\n"
        )?;
        write!(stream, "id: 0\nevent: run.started\ndata: {{}}\n\n")?;
        write!(stream, "id: 1\nevent: run.completed\ndata: {{\"reason\":\"mock\"}}\n\n")?;
        return Ok(());
    }
    let body = match (request.method.as_str(), route) {
        ("GET", "/health") => "{\"status\":\"ok\",\"service\":\"lightagent-mock\"}",
        ("GET", "/tools") => {
            "{\"tools\":[{\"name\":\"datetime.now\",\"risk\":\"read\",\"description\":\"Mock runtime tool (D2).\"}]}"
        }
        ("GET", "/skills") => "{\"skills\":[]}",
        ("GET", "/workers") => "{\"workers\":[]}",
        ("GET", "/approvals") => "{\"approvals\":[]}",
        ("GET", "/sessions") => "{\"sessions\":[]}",
        ("GET", "/sessions/search") => "{\"sessions\":[]}",
        ("GET", "/profiles") => {
            "{\"active_profile\":\"default\",\"profiles\":[{\"id\":\"default\",\"name\":\"Default\",\"model\":\"mock\",\"active\":true}]}"
        }
        ("GET", "/provider") => {

        }

/// Unattended-test evidence: when `LIGHTAGENT_DESKTOP_E2E_REPORT` names a

    started: Instant,
    seen: Mutex<HashSet<String>>,

    fn from_env() -> Self {
        Self {
            path: std::env::var_os("LIGHTAGENT_DESKTOP_E2E_REPORT").map(PathBuf::from),
            started: Instant::now(),
            seen: Mutex::default(),
        }
    }

    fn note_once(&self, tag: &str, detail: &str) {
        let Some(path) = &self.path else { return };

            return;
        }
        let line = format!("{tag} {detail} t_ms={}\n", self.started.elapsed().as_millis());
        if let Ok(mut file) = std::fs::OpenOptions::new().create(true).append(true).open(path) {
            let _ = file.write_all(line.as_bytes());
        }
    }
}

#[tauri::command]

    let mut status = RuntimeStatus {
        state: "starting",
        detail: None,
        desktop_version: VERSION,
        runtime_version: None,
        profile: None,
        capabilities: Vec::new(),
    };
    match &*lock(&host.runtime) {

        }
    }
    status
}

#[derive(Serialize)]
struct FetchResult {
    status: u16,

fn valid_filename(name: &str) -> bool {
    !name.is_empty()
        && name.len() <= 180
        && name != "."
        && name != ".."
        && name.chars().all(|c| c.is_ascii_alphanumeric() || matches!(c, '.' | '_' | ' ' | '-'))
}

#[tauri::command]
async fn api_fetch(
    host: tauri::State<'_, Arc<Host>>,
    method: String,
    target: String,
    body: Option<String>,
    body_base64: Option<String>,
    filename: Option<String>,
) -> Result<FetchResult, String> {
    let operation = host.contract.resolve(&method, &target)?.clone();
    if operation.stream {
        return Err(format!("{} is a stream; subscribe to it instead", operation.id));
    }
    let (base, authorization) = host.connection()?;
    let verb = reqwest::Method::from_bytes(method.as_bytes()).map_err(|_| "invalid method".to_owned())?;
    let mut request = host
        .http
        .request(verb, format!("{base}{target}"))
        .header(reqwest::header::AUTHORIZATION, authorization);
    if operation.raw_body {
        let bytes = base64::engine::general_purpose::STANDARD
            .decode(body_base64.unwrap_or_default())
            .map_err(|_| "the attachment is not valid base64".to_owned())?;
        let filename = filename
            .filter(|name| valid_filename(name))
            .ok_or("an attachment needs a plain file name")?;
        request = request.header("X-Lightagent-Filename", filename).body(bytes);
    } else if let Some(body) = body {
        request = request.header(reqwest::header::CONTENT_TYPE, "application/json").body(body);
    }
    let response = request
        .send()
        .await
        .map_err(|error| format!("the runtime did not answer: {}", error.without_url()))?;
    let status = response.status().as_u16();
    let content_type = response
        .headers()
        .get(reqwest::header::CONTENT_TYPE)
        .and_then(|value| value.to_str().ok())
        .unwrap_or("")
        .to_owned();
    let body = response
        .text()
        .await
        .map_err(|error| format!("the runtime's answer was cut off: {}", error.without_url()))?;
    if (200..300).contains(&status) {
        host.e2e.note_once("API_OK", &operation.id);
    }
    Ok(FetchResult { status, content_type, body })
}

#[tauri::command]
async fn api_subscribe(host: tauri::State<'_, Arc<Host>>, target: String) -> Result<u64, String> {
    let operation = host.contract.resolve("GET", &target)?;
    if !operation.stream {
        return Err(format!("{} is not a stream", operation.id));
    }
    let (base, authorization) = host.connection()?;
    let request = host
        .http
        .get(format!("{base}{target}"))
        .header(reqwest::header::AUTHORIZATION, authorization)
        .header(reqwest::header::ACCEPT, "text/event-stream");
    let id = host.next_subscription.fetch_add(1, Ordering::Relaxed);
    let subscription = Arc::new(Subscription::default());
    lock(&host.subscriptions).insert(id, Arc::clone(&subscription));
    let relay = Arc::clone(&subscription);
    let task = tauri::async_runtime::spawn(async move {
        let outcome = relay_stream(request, &relay).await;
        {
            let mut state = lock(&relay.state);
            state.closed = true;
            state.error = outcome.err();
        }
        relay.notify.notify_waiters();
    });
    *lock(&subscription.task) = Some(task);
    Ok(id)
}

async fn relay_stream(request: reqwest::RequestBuilder, subscription: &Subscription) -> Result<(), String> {
    let response = request
        .send()
        .await
        .map_err(|error| format!("the runtime did not answer: {}", error.without_url()))?;
    if !response.status().is_success() {
        return Err(format!("the runtime refused the stream ({})", response.status().as_u16()));
    }
    let mut parser = sse::SseParser::default();
    let mut stream = response.bytes_stream();
    while let Some(chunk) = stream.next().await {
        let chunk = chunk.map_err(|error| format!("the stream broke: {}", error.without_url()))?;
        let events = parser.push(&chunk);
        if !events.is_empty() {
            lock(&subscription.state).events.extend(events);
            subscription.notify.notify_waiters();
        }
    }
    Ok(())
}

#[derive(Serialize)]
struct PollResult {
    events: Vec<sse::SseEvent>,
    closed: bool,
    error: Option<String>,
}

fn drain(state: &mut SubscriptionState) -> PollResult {
    let events: Vec<_> = state.events.drain(..).collect();
    PollResult { events, closed: state.closed, error: state.error.clone() }
}

#[tauri::command]
async fn api_events_poll(host: tauri::State<'_, Arc<Host>>, subscription: u64, wait_ms: u64) -> Result<PollResult, String> {
    let entry = lock(&host.subscriptions)
        .get(&subscription)
        .cloned()
        .ok_or("unknown subscription")?;
    // Register for a wake-up before looking, so an event that lands in
    // between is never missed.
    let mut notified = std::pin::pin!(entry.notify.notified());
    notified.as_mut().enable();
    let ready = {
        let state = lock(&entry.state);
        !state.events.is_empty() || state.closed
    };
    if !ready {
        let _ = tokio::time::timeout(Duration::from_millis(wait_ms).min(MAX_POLL), notified).await;
    }
    let result = drain(&mut lock(&entry.state));
    if result.closed {
        lock(&host.subscriptions).remove(&subscription);
    }
    Ok(result)
}

#[tauri::command]
fn api_unsubscribe(host: tauri::State<'_, Arc<Host>>, subscription: u64) {
    if let Some(entry) = lock(&host.subscriptions).remove(&subscription)
        && let Some(task) = lock(&entry.task).take()
    {
        task.abort();
    }
}

#[tauri::command]
fn e2e_note(host: tauri::State<'_, Arc<Host>>, note: String) -> Result<(), String> {
    match note.as_str() {
        "ui_ready" => host.e2e.note_once("UI_READY", ""),
        "ui_error" => host.e2e.note_once("UI_ERROR", ""),
        _ => return Err("unknown note".to_owned()),
    }
    Ok(())
}

fn start_runtime(host: &Host) {
    let launched = sidecar::bundled_binary()
        .map_err(sidecar::LaunchError::Failed)
        .and_then(|binary| sidecar::launch(&binary, None, VERSION));
    let next = match launched {
        Ok(sidecar) => {
            host.e2e.note_once("RUNTIME_READY", &format!("version={}", sidecar.handshake.version));
            Runtime::Ready(sidecar)
        }
        Err(sidecar::LaunchError::Failed(reason)) => {
            host.e2e.note_once("RUNTIME_FAILED", "");
            Runtime::Failed(reason)
        }
        Err(sidecar::LaunchError::Mismatch { expected, found }) => {
            host.e2e.note_once("HANDSHAKE_MISMATCH", &format!("expected={expected} found={found}"));
            Runtime::Mismatch { expected, found }
        }
    };
    *lock(&host.runtime) = next;
}

fn main() {
    let contract = match contract::Contract::load() {
        Ok(contract) => contract,
        Err(error) => {
            eprintln!("{error}");
            std::process::exit(1);
        }
    };
    // Loopback only: never through a proxy from the environment, and never
    // following a redirect that would carry the credential elsewhere.
    let http = match reqwest::Client::builder()
        .no_proxy()
        .redirect(reqwest::redirect::Policy::none())
        .connect_timeout(Duration::from_secs(5))
        .build()
    {
        Ok(http) => http,
        Err(error) => {
            eprintln!("could not build the HTTP client: {error}");
            std::process::exit(1);
        }
    };
    let host = Arc::new(Host {
        contract,
        runtime: Mutex::new(Runtime::Starting),
        http,
        subscriptions: Mutex::default(),
        next_subscription: AtomicU64::new(1),
        e2e: E2e::from_env(),
    });
    let app = tauri::Builder::default()
        .manage(Arc::clone(&host))
        .invoke_handler(tauri::generate_handler![
            runtime_status,
            runtime_logs,
            api_fetch,
            api_subscribe,
            api_events_poll,
            api_unsubscribe,
            e2e_note
        ])
        .on_page_load(|webview, payload| {
            if matches!(payload.event(), tauri::webview::PageLoadEvent::Finished)
                && let Some(host) = webview.try_state::<Arc<Host>>()
            {

            }
        })
        .setup(|app| {
            let host = Arc::clone(app.state::<Arc<Host>>().inner());
            std::thread::spawn(move || start_runtime(&host));
            Ok(())
        })
        .build(tauri::generate_context!());

        Ok(app) => app,
        Err(error) => {
            eprintln!("could not start the window: {error}");
            std::process::exit(1);
        }
    };

        if let tauri::RunEvent::Exit = event
            && let Some(host) = app.try_state::<Arc<Host>>()
        {
            host.stop_runtime();
        }
    });
}
=== write desktop/src-tauri/src/sidecar.rs
//! Launching and owning the bundled runtime.
//!
//! The host starts exactly one binary: the `lightagent-sidecar` shipped next
//! to its own executable (never one found on `PATH`). The per-launch key is a
//! fresh 256-bit value from the OS generator, written once to the child's
//! stdin and then the pipe is closed; it never appears in argv, the
//! environment, a URL, a file, a log line, or the UI. The child answers with
//! one JSON handshake line on stdout, and is refused unless its protocol and
//! version match this build.

use std::collections::VecDeque;
use std::io::{BufRead as _, BufReader, Read, Write as _};
use std::path::{Path, PathBuf};
use std::process::{Child, Command, Stdio};
use std::sync::mpsc;
use std::sync::{Arc, Mutex};
use std::time::Duration;

use serde::Deserialize;

/// How long a starting runtime may take to report ready.
pub const READY_TIMEOUT: Duration = Duration::from_secs(20);
/// Lines of runtime output kept in memory for diagnostics.
const LOG_LINES: usize = 2_000;

/// The one line a runtime prints when it is ready.
#[derive(Clone, Debug, Deserialize)]
pub struct Handshake {
    pub lightagent: String,
    pub protocol: u32,
    pub version: String,
    pub addr: String,
    #[serde(default)]
    pub profile: Option<String>,
    #[serde(default)]
    pub capabilities: Vec<String>,
}

/// Why a runtime did not become usable.
#[derive(Debug)]
pub enum LaunchError {
    Failed(String),
    Mismatch { expected: String, found: String },
}

/// A running, owned runtime.
pub struct Sidecar {
    child: Child,
    key: String,
    pub handshake: Handshake,
    pub logs: Arc<Mutex<VecDeque<String>>>,
}

impl Sidecar {
    pub fn base_url(&self) -> String {
        format!("http://{}", self.handshake.addr)
    }

    pub fn authorization(&self) -> String {
        format!("Bearer {}", self.key)
    }

    /// Stop the runtime this host started, and nothing else.
    pub fn stop(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
    }
}

impl Drop for Sidecar {
    fn drop(&mut self) {
        self.stop();
        // Overwrite the key before its memory is released.
        let len = self.key.len();
        self.key.clear();
        self.key.extend(std::iter::repeat_n('0', len));
    }
}

/// The bundled runtime: next to the host's own executable.
pub fn bundled_binary() -> Result<PathBuf, String> {
    let exe = std::env::current_exe().map_err(|error| format!("cannot locate the app: {error}"))?;
    let dir = exe.parent().ok_or("the app has no directory")?;
    let name = if cfg!(windows) { "lightagent-sidecar.exe" } else { "lightagent-sidecar" };
    let path = dir.join(name);
    if path.is_file() {
        Ok(path)
    } else {
        Err(format!("the bundled runtime is missing ({name} next to the app)"))
    }
}

fn new_key() -> Result<String, String> {
    let mut bytes = [0u8; 32];
    getrandom::fill(&mut bytes).map_err(|_| "the OS random source is unavailable".to_owned())?;
    Ok(bytes.iter().map(|byte| format!("{byte:02x}")).collect())
}

/// Start `binary` as an owned runtime for `profile` and wait for its handshake.
pub fn launch(binary: &Path, profile: Option<&str>, expected_version: &str) -> Result<Sidecar, LaunchError> {
    let key = new_key().map_err(LaunchError::Failed)?;
    let mut command = Command::new(binary);
    command
        .args(["serve", "--desktop", "--host", "127.0.0.1", "--port", "0"])
        .arg("--parent-pid")
        .arg(std::process::id().to_string())
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped());
    if let Some(profile) = profile {
        command.arg("--profile").arg(profile);
    }
    #[cfg(windows)]
    {
        use std::os::windows::process::CommandExt as _;
        const CREATE_NO_WINDOW: u32 = 0x0800_0000;
        command.creation_flags(CREATE_NO_WINDOW);
    }
    let mut child = command
        .spawn()
        .map_err(|error| LaunchError::Failed(format!("could not start the runtime: {error}")))?;

    // Deliver the key and close stdin so the runtime sees end-of-input.
    let delivered = child
        .stdin
        .take()
        .map(|mut stdin| stdin.write_all(format!("{key}\n").as_bytes()))
        .transpose();
    if !matches!(delivered, Ok(Some(()))) {
        let _ = child.kill();
        return Err(LaunchError::Failed("could not hand the runtime its credential".to_owned()));
    }

    let logs = Arc::new(Mutex::new(VecDeque::with_capacity(LOG_LINES)));
    let (ready_tx, ready_rx) = mpsc::channel::<String>();
    if let Some(stdout) = child.stdout.take() {
        let logs = Arc::clone(&logs);
        let key = key.clone();
        std::thread::spawn(move || pump(stdout, &logs, &key, Some(ready_tx)));
    }
    if let Some(stderr) = child.stderr.take() {
        let logs = Arc::clone(&logs);
        let key = key.clone();
        std::thread::spawn(move || pump(stderr, &logs, &key, None));
    }

    let line = match ready_rx.recv_timeout(READY_TIMEOUT) {
        Ok(line) => line,
        Err(error) => {
            let _ = child.kill();
            let _ = child.wait();
            return Err(LaunchError::Failed(match error {
                mpsc::RecvTimeoutError::Timeout => format!(
                    "the runtime did not report ready within {} s",
                    READY_TIMEOUT.as_secs()
                ),
                mpsc::RecvTimeoutError::Disconnected => {
                    "the runtime exited before reporting ready".to_owned()
                }
            }));
        }
    };
    let handshake: Handshake = match serde_json::from_str(&line) {
        Ok(handshake) => handshake,
        Err(_) => {
            let _ = child.kill();
            let _ = child.wait();
            return Err(LaunchError::Failed("the runtime's ready line is not a handshake".to_owned()));
        }
    };
    let mut sidecar = Sidecar { child, key, handshake, logs };
    if sidecar.handshake.lightagent != "serve" || sidecar.handshake.protocol != crate::contract::PROTOCOL {
        let found = format!("{} protocol {}", sidecar.handshake.lightagent, sidecar.handshake.protocol);
        sidecar.stop();
        return Err(LaunchError::Mismatch {
            expected: format!("serve protocol {}", crate::contract::PROTOCOL),
            found,
        });
    }
    if sidecar.handshake.version != expected_version {
        let found = sidecar.handshake.version.clone();
        sidecar.stop();
        return Err(LaunchError::Mismatch { expected: expected_version.to_owned(), found });
    }
    if !is_loopback_addr(&sidecar.handshake.addr) {
        sidecar.stop();
        return Err(LaunchError::Failed("the runtime is not bound to 127.0.0.1".to_owned()));
    }
    Ok(sidecar)
}

fn is_loopback_addr(addr: &str) -> bool {
    addr.strip_prefix("127.0.0.1:")
        .is_some_and(|port| !port.is_empty() && port.bytes().all(|byte| byte.is_ascii_digit()))
}

/// Copy one output stream into the bounded log, redacting the key should it
/// ever appear, and hand the first stdout line to the launcher.
fn pump(stream: impl Read, logs: &Mutex<VecDeque<String>>, key: &str, mut ready: Option<mpsc::Sender<String>>) {
    for line in BufReader::new(stream).lines() {
        let Ok(line) = line else { break };
        let line = line.replace(key, "<redacted>");
        if let Some(sender) = ready.take() {
            let _ = sender.send(line.clone());
        }
        if let Ok(mut logs) = logs.lock() {
            if logs.len() == LOG_LINES {
                logs.pop_front();
            }
            logs.push_back(line);
        }
    }
}

//! The operation contract: the only requests the UI may have the host make.
//!
//! The contract is `docs/desktop/contract/operations.json`, embedded at build
//! time and kept equal to the server's routes by
//! `scripts/check-desktop-contract.py`. A request that matches no operation,
//! carries an unlisted query parameter, or has a path segment outside the
//! identifier alphabet is refused before any connection is made.

use serde::Deserialize;

const CONTRACT: &str = include_str!("../../../docs/desktop/contract/operations.json");

/// The protocol version the contract describes; the runtime's handshake must
/// report the same.
pub const PROTOCOL: u32 = 1;

#[derive(Debug, Deserialize)]
pub struct Contract {
    pub protocol: u32,
    pub operations: Vec<Operation>,
}

#[derive(Clone, Debug, Deserialize)]
pub struct Operation {
    pub id: String,
    pub method: String,
    pub path: String,
    #[serde(default)]
    pub query: Vec<String>,
    #[serde(default)]
    pub stream: bool,
    #[serde(default)]
    pub raw_body: bool,
}

impl Contract {
    pub fn load() -> Result<Self, String> {
        let contract: Self = serde_json::from_str(CONTRACT)
            .map_err(|error| format!("the operation contract is malformed: {error}"))?;
        if contract.protocol != PROTOCOL {
            return Err(format!(
                "the operation contract is protocol {}, the host speaks {PROTOCOL}",
                contract.protocol
            ));
        }
        Ok(contract)
    }

    /// The operation `method target` names, where `target` is a path with an
    /// optional query string.
    pub fn resolve(&self, method: &str, target: &str) -> Result<&Operation, String> {
        if target.contains('#') {
            return Err("a request target may not carry a fragment".to_owned());
        }
        let (path, query) = target.split_once('?').unwrap_or((target, ""));
        let operation = self
            .operations
            .iter()
            .find(|operation| operation.method == method && matches(&operation.path, path))
            .ok_or_else(|| format!("{method} {path} is not in the desktop operation contract"))?;
        for pair in query.split('&').filter(|pair| !pair.is_empty()) {
            let key = pair.split_once('=').map_or(pair, |(key, _)| key);
            if !operation.query.iter().any(|allowed| allowed == key) {
                return Err(format!(
                    "query parameter {key:?} is not allowed for {}",
                    operation.id
                ));
            }
        }
        Ok(operation)
    }
}

fn matches(template: &str, path: &str) -> bool {
    let template: Vec<&str> = template.split('/').collect();
    let path: Vec<&str> = path.split('/').collect();
    template.len() == path.len()
        && template.iter().zip(&path).all(|(expected, actual)| {
            if expected.starts_with('{') && expected.ends_with('}') {
                valid_segment(actual)
            } else {
                expected == actual
            }
        })
}

/// An identifier segment: letters, digits, `-`, `_`, `.` and `:`, at most
/// 200 bytes, and never only dots.
fn valid_segment(segment: &str) -> bool {
    !segment.is_empty()
        && segment.len() <= 200
        && !segment.bytes().all(|byte| byte == b'.')
        && segment
            .bytes()
            .all(|byte| byte.is_ascii_alphanumeric() || matches!(byte, b'-' | b'_' | b'.' | b':'))
}

//! A server-sent-events parser for the host's relay of run streams.
//!
//! The relay forwards each event's `id`, `event` and `data` unchanged, so the
//! UI's existing sequencing (ordered ids, gap detection, `?after=` replay in
//! `frontend/src/hooks/useRunEvents.ts`) behaves exactly as with a browser
//! `EventSource`.

use serde::Serialize;

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct SseEvent {
    pub id: Option<String>,
    pub event: String,
    pub data: String,
}

/// Incremental parser: feed it byte chunks as they arrive, in any split.
#[derive(Default)]
pub struct SseParser {
    buffer: Vec<u8>,
    id: Option<String>,
    event: Option<String>,
    data: Vec<String>,
}

impl SseParser {
    pub fn push(&mut self, chunk: &[u8]) -> Vec<SseEvent> {
        self.buffer.extend_from_slice(chunk);
        let mut events = Vec::new();
        while let Some(end) = self.buffer.iter().position(|&byte| byte == b'\n') {
            let line: Vec<u8> = self.buffer.drain(..=end).collect();
            // A whole line is complete UTF-8 even when a chunk split a character.
            let line = String::from_utf8_lossy(&line);
            let line = line.trim_end_matches(['\n', '\r']);
            if line.is_empty() {
                if !self.data.is_empty() || self.event.is_some() {
                    events.push(SseEvent {
                        id: self.id.clone(),
                        event: self.event.take().unwrap_or_else(|| "message".to_owned()),
                        data: self.data.join("\n"),
                    });
                    self.data.clear();
                }
                continue;
            }
            if line.starts_with(':') {
                continue;
            }
            let (field, value) = match line.split_once(':') {
                Some((field, value)) => (field, value.strip_prefix(' ').unwrap_or(value)),
                None => (line, ""),
            };
            match field {
                "data" => self.data.push(value.to_owned()),
                "event" => self.event = Some(value.to_owned()),
                // The last id persists across events, as `lastEventId` does.
                "id" if !value.contains('\0') => self.id = Some(value.to_owned()),
                _ => {}
            }
        }
        events
    }
}

EXPECT = {

    "mismatch": ["HANDSHAKE_MISMATCH", "PAGE_LOADED", "UI_ERROR"],
}
KEY_SHAPE = re.compile(r"\b[0-9a-f]{64}\b")


def screenshot(path):
    try:
        if sys.platform == "darwin":
            subprocess.run(["screencapture", "-x", path], check=True, timeout=30)
        elif sys.platform.startswith("linux"):
            subprocess.run(["import", "-window", "root", path], check=True, timeout=30)
        else:
            from PIL import ImageGrab

            ImageGrab.grab().save(path)
        return True
    except Exception as error:
        print(f"screenshot failed: {error}")
        return False


def tree(pid):
    try:
        root = psutil.Process(pid)
        return [root] + root.children(recursive=True)
    except psutil.Error:
        return []


def main():
    out = os.path.abspath(sys.argv[1])
    mode = sys.argv[2]
    command = sys.argv[sys.argv.index("--") + 1:]
    os.makedirs(out, exist_ok=True)
    report = os.path.join(out, f"report-{mode}.txt")
    if os.path.exists(report):
        os.remove(report)
    env = dict(os.environ, LIGHTAGENT_DESKTOP_E2E_REPORT=report)
    started = time.time()
    app = subprocess.Popen(command, env=env)
    want = EXPECT[mode]
    seen = {}
    while time.time() - started < 90 and app.poll() is None:
        text = open(report, encoding="utf-8").read() if os.path.exists(report) else ""
        for tag in want:
            if tag not in seen and any(line.startswith(tag) for line in text.splitlines()):
                seen[tag] = round(time.time() - started, 3)
        if len(seen) == len(want):
            break
        time.sleep(0.1)
    time.sleep(2)
    result = {"mode": mode, "milestones_s": seen, "missing": [t for t in want if t not in seen]}
    result["screenshot"] = screenshot(os.path.join(out, f"screenshot-{mode}.png"))

    processes = tree(app.pid)
    result["processes"] = [p.name() for p in processes if p.is_running()]
    leaks = []
    for process in processes:
        try:
            if KEY_SHAPE.search(" ".join(process.cmdline())):
                leaks.append(f"argv of {process.name()}")
        except psutil.Error:
            pass
        try:
            if any(KEY_SHAPE.search(value) for value in process.environ().values()):
                leaks.append(f"environment of {process.name()}")
        except psutil.Error:
            pass  # not readable on every OS; recorded below
    report_text = open(report, encoding="utf-8").read() if os.path.exists(report) else ""
    if KEY_SHAPE.search(report_text):
        leaks.append("e2e report")
    result["key_leaks"] = leaks
    result["report"] = report_text.splitlines()

    sidecars = [p for p in processes if "sidecar" in p.name()]
    app.terminate()
    try:
        app.wait(timeout=15)
    except subprocess.TimeoutExpired:
        app.kill()
    time.sleep(3)
    survivors = [p for p in sidecars if p.is_running()]
    result["runtime_survived_host_termination"] = bool(survivors)
    for process in survivors:
        process.kill()

    with open(os.path.join(out, f"e2e-{mode}.json"), "w", encoding="utf-8") as handle:
        json.dump(result, handle, indent=1)
    print(json.dumps(result, indent=1))
    return 1 if result["missing"] or leaks else 0


if __name__ == "__main__":
    sys.exit(main())

### Audit findings that shape D1–D3

1. **The process model exists.** `lightagent serve` (`crates/lightagent/src/serve.rs:732`)
   serves `/api/lightagent/v1` (21 method/route pairs, `crates/lightagent-api/src/lib.rs:73-112`)
   and the React 19 + Vite WebUI from `--web-root` (`frontend/`; screens `/`, `/tools`, `/settings`).
2. **The API covers only part of the CLI.** It has no operation for config
   path/get/set and the Jev routing report, models, profile
   show/create/use/preset/delete, the extensions commands, worker
   assign/revoke, memory, RAG, identity, remote credentials, import, doctor,
   init/setup, onboard, reload, **continue** (resume after the time budget), or
   **steering** (input queued while a run is in progress).
3. **CLI handlers are print-bound.** They have the shape
   `fn(args…, json: bool) -> Result<(), String>` and print their results
   (for example `extensions.rs:27`, `rag.rs:697`, `import.rs:28`, `memory.rs`).
   Typed shared operations must be extracted (D3) so CLI, API, and desktop call
   the same code.
4. **Loopback is unauthenticated.** `serve.rs:746-758`: with no `--key-env`,
   a loopback bind uses `AuthConfig::open()`. `crates/lightagent-api` has no
   Host or Origin validation, so a DNS-rebinding page or any local process can
   drive tools. This is an input to the D1 security design.
5. **One profile per server process.** `AppState.session_profile` is fixed
   at start (`serve.rs:739-760`). `POST /runs {profile}` is honoured only in
   multi-user mode (`lib.rs:1148-1160`). The active-profile write
   `ProfileStore::set_active` is atomic (temp file + rename,
   `paths.rs:173-185`), but no lock coordinates a running server with a CLI
   that switches profile. This is an input to the D1 profile-switch decision.
6. **Secret authority.** Provider keys are stored in owner-only
   `~/.lightagent/secrets` and referenced as `SecretRef`. The
   remote-credential vault is sealed with
   `LIGHTAGENT_CREDENTIAL_KEY[_FILE]`. Identity secrets have strict delivery
   rules (`identity_admin.rs:10-14`).
7. **Targets and runners.** `check.yml` and `release.yml` already run
   natively on `macos-15-intel` (x86_64, `MACOSX_DEPLOYMENT_TARGET=10.14`),
   `macos-15` (arm64, 11.0), `windows-latest`, and `ubuntu-22.04`/`24.04`.
   The 10.14 floor is a declared deployment target; no hosted runner executes
   macOS older than 15. It stays an unverified target (D1).
